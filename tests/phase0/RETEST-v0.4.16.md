# v0.4.16 Excel主出力 再検証手順

## 重要

最初はExcelをすべて閉じ、メニュー0の後にメニュー12だけを実行してください。
単発と生成xlsxの目視確認が終わるまで、10回試験へ進まないでください。

タイムアウト時、監督スクリプトは子PowerShellだけを停止し、EXCELを自動終了しません。
その場合は開いているブックを保存できる範囲で保存し、PCを再起動してから結果を共有してください。

## 1. ゲート

1. `run.cmd` をダブルクリックする。
2. メニュー0を実行する。
3. 次を確認する。
   - `Excel.Application の型解決` が使える
   - `09-excel-layout.ps1` の構文がOK
   - `09-excel-layout-supervisor.ps1` の構文がOK
   - UTF-8 BOMなしのps1がない

この段階で構文NGならメニュー12へ進まず、`result-00-gate.txt` を共有してください。

## 2. Excel単発試験

1. Excelのウィンドウをすべて閉じる。
2. タスクマネージャーでEXCELが残っていないことを確認する。
3. メニュー12を実行する。
4. 次を確認する。
   - 自インスタンスのPID特定がOK
   - Excel設定がPID確認後に適用されている
   - X-01、X-02、X-05、X-06、X-07、X-08、X-10、X-13がOK
   - NGが0
   - 監督判定がOK
   - 新しいEXCEL PIDの残留が0
   - `out\excel\` にxlsxが1件増える
   - `out\excel\.tmp\` が空
   - 印刷設定がWARNでも、xlsxが生成されていれば単発試験は続行できる
   - シート名が拒否された場合は「手順シート N」の代替名で生成を続行する
   - 目次行番号・概要・手順数・目次リンクの設定を通過する

生成されたxlsx、`out\excel\result-09-excel.txt`、
`out\excel\result-09-supervisor.txt` を保存してください。

## 3. 生成xlsxの目視確認

生成されたxlsxを開き、次を確認します。

1. シート順が `目次 → ログイン → 経費・申請・国内 → ログイン (2)`。
2. 目次の3リンクで各シートへ移動できる。
3. 各シートの「目次へ戻る」で目次へ戻れる。
   - 濃紺の見出し帯上で「目次へ戻る」が白字・太字ではっきり読める。
4. 各手順で画像が左、説明・補足が右に同時表示される。
5. 各シートの手順番号が1、2で始まる。
6. 横長・縦長の画像が変形せず、カード外や次の手順へ重ならない。
7. 説明・補足セルを直接編集できる。
8. 補足が薄い黄色、カード境界だけが薄い罫線。
9. グリッド線非表示、ズーム90%、上部2行固定。
10. 1366×768・Windows 125%表示で画像と説明を同時に読める。
11. マクロ警告が出ず、ファイル形式が `.xlsx`。

目視結果が分かるスクリーンショットと生成xlsxを共有してください。

## 4. 10回・キャンセル・異常分岐

単発と目視確認が合格した場合だけ進めます。

1. 生成xlsxを閉じ、Excelをすべて終了する。
2. メニュー13を実行する。
   - 10ラウンドすべて結果コード0
   - 各ラウンドでxlsxが1件生成
   - 各ラウンドで新しいEXCEL PIDの残留0
3. Excelを閉じたままメニュー14を実行する。
   - 全体手順3の直前でキャンセル
   - 完成xlsxが増えない
   - `.tmp` が空
   - EXCEL残留0
4. メニュー15を実行する。
   - Excel COMを起動しない
   - 完成xlsxが増えない
   - EXCEL残留0

## 5. 既存の未保存Excel保護

1. Excelを手動で起動し、新しい空白ブックを開く。
2. A1に `この文字は未保存のまま残す` と入力し、保存しない。
3. メニュー12を実行する。
4. 次のどちらかなら安全側の結果です。
   - 新しい所有PIDを証明して、別インスタンスでxlsxを生成する
   - 所有PIDを証明できず、設定変更前に出力を中止する
5. 必須条件:
   - 手動で開いたExcelと未保存文字が残る
   - そのExcelが終了しない
   - 警告設定や画面更新設定が変わらない

既存Excel起動中に安全中止した場合、製品要件は「Excelを閉じてから出力」に確定します。

## 6. タイムアウト・異常時

- 120秒で止まったら、その後にメニュー13を実行しない
- タスクマネージャーからEXCELを機械的に終了しない
- 開いているブックを保存できる場合だけ保存し、PCを再起動する
- 次を共有する
  - コンソールの最後の表示
  - `out\excel\result-09-excel.txt`
  - `out\excel\result-09-supervisor.txt`
  - `out\excel\.tmp\` の中身
  - タスクマネージャーのEXCEL PID
