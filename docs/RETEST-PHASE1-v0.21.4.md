# ManualBuilder Phase 1 v0.21.4 再確認

## 自動テスト

```powershell
cd "$env:USERPROFILE\Downloads\ManualBuilder"
tests\phase1\run-tests.cmd
```

Excelをすべて閉じた後に実行します。

```powershell
tests\phase1\run-excel-test.cmd
```

## 実画面で確認すること

1. 日本語と英数字が混在する長い説明でも、文章の末尾から次のカードまで過剰な空白が残らない
2. 長文が途中で切れず、説明欄の白い領域が本文に必要な高さで終わる
3. 小さい範囲を撮影・切り抜きした場合、編集画面の横幅いっぱいまで不自然に拡大されない。3:1以上の横長画像は通常幅の85%以内になる
4. 小画像は画像領域の中央に表示され、赤枠・番号も画像と同じ位置・倍率で表示される
5. Excelでは小画像の最大1.5倍、編集画面では最大1.25倍の方針が反映される
6. 通常の全画面スクリーンショットは従来どおり画像領域へ収まる

## 期待する自動テスト表示

- `長文を文字幅と物理行高から見積もって余白を抑える`
- `半角英数字を実表示幅に近い文字数として見積もる`
- `編集画面で小さく細長い画像の過拡大を抑える`
- `Excelで小さな元画像の拡大を最大1.5倍に抑える`
- `Excelで細長い画像を通常幅の85%へ抑える`
