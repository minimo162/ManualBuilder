# ManualBuilder Phase 1 v0.19.0 再確認

## 1. 基本回帰

```powershell
cd "$env:USERPROFILE\Downloads\ManualBuilder"
tests\phase1\run-tests.cmd
```

すべて `All Phase 1 foundation tests passed.` になることを確認します。

## 2. 編集表示

1. `run.cmd` で起動し、右下が `v0.19.0` であることを確認します。
2. 上部のマニュアル名とシート名の右側に、小さな青い `✎ 編集` が常時見えることを確認します。
3. `✎ 編集` が名前から離れすぎず、名前欄をクリックすると従来どおり直接変更できることを確認します。
4. 手順名ラベルにも `✎ 編集` が見え、説明・補足とは区別できることを確認します。
5. 1920×1080・100%と、可能なら1920×1200・150%でも保存状態やExcel作成ボタンが隠れないことを確認します。

## 3. Excelデザイン

Excelをすべて閉じてから作成します。

```powershell
tests\phase1\run-excel-test.cmd
```

製品画面からもExcelを作成し、次を目視します。

1. 目次の上部が濃紺のヘッダーで、タイトルと更新情報が読みやすい。
2. 目次行でシート名が主、概要と手順数が従として見える。
3. 各シートの先頭も濃紺で、白文字のシート名と「目次へ戻る」が見える。
4. 手順番号が `STEP 01` 形式で、画像・説明・補足の境界が分かる。
5. 画像サイズは従来の約800×450px相当を維持している。
6. 補足がない手順に黄色い領域が出ない。
7. シートタブに青系のテーマ色が付く。
8. 出力後にExcelプロセスが残らず、既存の未保存ブックへ影響しない。
