# Phase 1 v0.9 ナビゲーション・画像編集・Excel表示 再確認

## 1. 差し替え前

1. ManualBuilderを終了する。
2. Excelをすべて閉じる。
3. ZIPの`ManualBuilder`フォルダーを既存リポジトリへ上書きする。
4. `data`フォルダーは削除・上書きしない。

## 2. 自動テスト

Windows PowerShell 5.1でリポジトリ直下から実行する。

```powershell
tests\phase1\run-tests.cmd
```

`All Phase 1 foundation tests passed.`を確認する。新しい検査として、次の3項目が`[OK]`になることを確認する。

- 左ナビの重複する矢印移動を表示しない
- 画像編集を明確な主操作として表示する
- Excel画像領域の高さを16対9画面向けに拡大する
- Excelで切り抜いた小領域を最大2倍まで拡大する

続けて、Excelをすべて閉じて実行する。

```powershell
tests\phase1\run-excel-test.cmd
```

`1920x1080画像を約800x450px相当で配置する`と、最後の`Excel export test passed.`を確認する。

## 3. 左ナビゲーション

1. 手順を4件以上用意する。
2. 上下矢印が表示されず、ドラッグハンドルと削除だけになっていることを確認する。
3. ハンドルをドラッグし、上方向と下方向へ並べ替えられることを確認する。
4. 並べ替え後も対象の手順が選択されたままであることを確認する。
5. 再起動後も順序が保持されることを確認する。

## 4. 画像編集ボタン

1. 画像付き手順を開く。
2. 画像の下に青いアイコン、`画像を編集・注釈`、`編集を開く`が常時表示されることを確認する。
3. ボタンのどこを押しても画像編集画面が開くことを確認する。
4. 注釈件数と`切り抜き済み`表示が以前と同じように更新されることを確認する。

## 5. Excel表示

1. 1920×1080または1920×1200・100%で`Excelで作成`を実行する。
2. 手順カードがA:Lの12列を使い、横スクロールなし、または最小限の横移動で見られることを確認する。
3. 16:9のスクリーンショットが従来の約460×260pxから、約800×450px相当へ拡大されていることを確認する。
4. 画像の右側に説明と補足が表示され、画像と文章を同時に読めることを確認する。
5. 切り抜き・注釈がExcel画像へ反映されることを確認する。
6. 小さく切り抜いた範囲が、元のピクセル寸法のまま小さく残らず、読みやすい範囲で拡大されることを確認する。

## 6. 安全性

- 元の画像ファイルが変更されない。
- 既存の未保存Excelブックへ影響しない。
- 出力後に専用の`EXCEL.EXE`が残らない。
- `tests\phase0`に差分がない。
