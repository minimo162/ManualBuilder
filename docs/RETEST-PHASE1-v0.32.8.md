# Phase 1 v0.32.8 再確認手順

v0.32.8は、「操作を記録して手順にする」でブラウザーのページ全体に赤枠が付き、実際にクリックしたリンクやボタンに枠が付かない問題を修正した版です。

## 自動検査

Windowsで次を実行します。

```text
tests\phase1\run-tests.cmd
```

最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。操作記録の検査では、ページ全体のDocument、リンク内のText、リンク、名前のないボタンが同じ点に重なる場合の選択と、ページ全体に近い矩形の除外を確認します。

## 目視確認

1. `run.cmd` からManualBuilderを起動する
2. その他メニューから「操作を記録して手順にする」を開始する
3. EdgeまたはChromeで、ページ上部・中央・下部にあるリンクをそれぞれクリックする
4. ボタン、チェックボックス、プルダウンもそれぞれクリックする
5. 記録を停止し、操作を取り込む
6. 赤枠がページ全体ではなく、クリックしたリンク・ボタンなどの輪郭に付くことを確認する
7. UI Automationで操作対象を特定できない場所をクリックした場合、ページ全体の赤枠が付かないことを確認する
8. 入力欄へ文字を入力した場合、入力欄だけが黒塗りされ、ページ全体が黒塗りされないことを確認する
9. 画面左下の版数が `v0.32.8` になっていることを確認する

## 修正内容

- UI Automationの `FromPoint` がDocument/Paneを返した場合、クリック点を含む子要素を最大10階層探索
- Textなどの葉が返った場合は、リンクやボタンの親要素も探索
- ControlTypeに加え、InvokePatternなどの操作パターンを持つ要素も操作対象として採用
- 名前のないボタンも矩形が取得できれば赤枠の対象にする
- 操作可能な要素を特定できない場合は、名前付きDocument/Paneへフォールバックしない
- ページ全体に近い矩形を注釈作成の最終段でも除外
- 配布版数をv0.32.8へ更新
