# Phase 1 v0.33.1 再確認手順

## 自動検査

Windowsで `tests\phase1\run-tests.cmd` を実行し、最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。

## 記録用Edgeの起動継続

1. ManualBuilderを起動し、その他メニューから［操作を記録して手順にする］を開きます。
2. ［記録用Edgeを使う（推奨）］を選んだまま［記録を開始］を押します。
3. 記録用Edgeが開いた後、10秒以上そのまま開いていることを確認します。
4. 任意のWebページへ移動し、リンクやボタンを数件操作します。
5. ManualBuilderへ戻り、［記録を終了］を押します。

期待結果:

- 記録用Edgeが起動直後に閉じない。
- DOM監視の接続・再接続・キャッシュ書き込みで一時エラーが起きても、Edgeを閉じず再試行する。
- DOM監視プロセスが致命的に終了した場合は画面にフォールバックの案内が出て、Windowsの対象検出で記録を継続する。
- ［記録を終了］を押した場合は記録用Edgeが閉じる。
- 記録した操作を確認して手順へ取り込める。

## 再接続

1. 記録中に記録用Edgeで新しいタブを開く、またはページを連続して移動します。
2. その後、リンクまたはボタンを操作します。

期待結果:

- CDPの接続先が切り替わってもDOM監視を再接続する。
- 再接続時に同じbindingが残っていても記録を終了しない。

DOM要素の矩形と表示倍率の確認は [v0.33.0の再確認手順](RETEST-PHASE1-v0.33.0.md) も参照してください。
