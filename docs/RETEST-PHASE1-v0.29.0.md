# Phase 1基盤 v0.29.0 再確認手順

操作を記録して手順にするモードを確認します。

v0.28.0（録画からの自動分割）との違いは、**押された場所を推定しない**ことです。
Windows の UI Automation が持っているコントロールの名前と矩形をそのまま読むため、
赤枠の位置も操作対象の名前も確定値になります。

前提: Windows 10/11・PowerShell 5.1。管理者権限は要りません。

---

## 0. 事前準備

1. `tests\phase1\run-tests.cmd` を実行し、すべて成功することを確認する。
   - `Test-Recorder.ps1` が新しく加わっています。
   - この環境で記録できない場合、`Test-Recorder.ps1` は理由を表示したうえで成功します。
2. 記録対象の業務アプリを1つ開いておく。関係のないウィンドウは閉じておく。

---

## 1. 記録できるかの判定

その他メニューから **［操作を記録して手順にする］** を開きます。

| # | 確認内容 | 期待 |
|---|----------|------|
| 1-1 | 判定の表示 | 「押したボタンの名前と位置をWindowsから直接取得します」と出る |
| 1-2 | 使えない環境 | 理由が表示され、［記録を開始］が押せない状態になる |
| 1-3 | 注意書き | 入力した文字を記録しないことが最初に書かれている |

---

## 2. 記録

［記録を開始］を押し、業務アプリで数回クリックしてから ManualBuilder へ戻り、
［記録を終了］を押します。

| # | 確認内容 | 期待 |
|---|----------|------|
| 2-1 | 件数の表示 | クリックするたびに件数が増える |
| 2-2 | 直前の操作 | 「直前: 申請」のように、押したボタンの名前が出る |
| 2-3 | 記録の継続 | ブラウザーを最小化しても記録が続く |
| 2-4 | タスクバー | タスクバーやデスクトップを押しても件数が増えない |
| 2-5 | 戻る操作 | ManualBuilder へ戻るためのクリックが記録されていない |

### 2-6. 押す直前の画面が写っていること

**この版で最も重要な確認です。** 一覧のサムネイルを見て、各手順の画像が
**押した直後ではなく、押す直前の画面**になっていることを確認してください。

押した後の画面が写っている場合、UI Automation の問い合わせが画面取得より先に
走っている可能性があります（本来は画面を先に確保する実装です）。その場合は
どのアプリで起きたかを記録してください。

## 3. 赤枠の位置

| # | 確認内容 | 期待 |
|---|----------|------|
| 3-1 | 位置 | 押したボタンの輪郭に沿って赤枠が付いている |
| 3-2 | 名前 | 一覧に、押したボタンの名前がそのまま出ている |
| 3-3 | 名前が取れない場合 | 「（名前を取得できませんでした）」と出るが、赤枠と画像は残る |
| 3-4 | メニュー | ウィンドウの外へ出るドロップダウンやメニューが切れずに写っている |

### 3-5. 高DPI環境での確認（重要）

**表示スケールを150%または200%にした状態で記録してください。**
赤枠が押したボタンからずれていないことを確認します。

ずれる場合、座標系の不一致（DPI認識の設定が効いていない）を疑ってください。
100%では問題が出ず、拡大時にだけ出るのがこの種の不具合の特徴です。

### 3-6. マルチモニターでの確認

サブモニター、特に**主モニターより左または上にあるモニター**で記録し、
赤枠の位置がずれないことを確認します。この配置では座標が負になります。

## 4. 入力の記録

入力欄に文字を打ってから、別の場所をクリックします。

| # | 確認内容 | 期待 |
|---|----------|------|
| 4-1 | 入力の手順 | 入力し終えた画面が1件の手順になる |
| 4-2 | 欄の名前 | 「金額（入力）」のように、入力先の名前が出る |
| 4-3 | 1文字ごとに増えない | 10文字打っても手順は1件 |

### 4-4. 入力文字が残っていないこと（重要）

**パスワード欄に文字を入力して記録し、取り込んだあとに確認してください。**

- 手順の文章・補足のどこにも、入力した文字が入っていない
- `%LOCALAPPDATA%\ManualBuilder\data\projects\<マニュアルID>\project.json` を
  テキストエディターで開き、入力した文字が含まれていない

画面に文字が表示される欄（伏せ字でない欄）では、**画像には写ります**。
これは仕様です。必要に応じて黒塗りしてください。

## 5. 取り込み

| # | 確認内容 | 期待 |
|---|----------|------|
| 5-1 | 選択 | 押し間違いのチェックを外して取り込める |
| 5-2 | 手順の作成 | 選んだぶんだけ手順ができ、赤枠が入っている |
| 5-3 | 同じ画面 | まったく同じ画面が続いた場合、除かれた件数が知らされる |
| 5-4 | 取り込まず閉じる | 閉じると記録した画面が残らない |
| 5-5 | 後片付け | `%LOCALAPPDATA%\ManualBuilder\data\recording-jobs` にジョブが残っていない |
