# ManualBuilder Phase 1 v0.21.5 再確認

## 修正内容

- Excel COMテストの横長カード期待値を、現仕様の8行から7行へ更新
- 高さが幅の3倍以上の画像をExcelで最大22行へ抑制
- 極端な縦長画像は表示可能高の85%（Excelで約620px相当）に収め、注釈の表示寸法も同じ倍率で合成
- 極端な横長画像は編集画面の画像フレーム自体を低くし、画像下の空白を縮小
- 編集画面では極端な縦長・横長とも最大1.25倍、Excelでは最大1.5倍の拡大上限を維持

## 自動確認

```powershell
tests\phase1\run-tests.cmd
```

Excelをすべて閉じてから、次も実行します。

```powershell
tests\phase1\run-excel-test.cmd
```

## 目視確認

1. 高さが幅の3倍以上の縦長画像を追加し、画像がカードいっぱいに過拡大されないこと
2. 幅が高さの3倍以上の横長画像を追加し、編集画面で画像下の大きな空白が減ること
3. 赤枠または番号を付けてExcelへ出力し、アプリ画面とExcelで注釈の見た目が大きく変わらないこと
4. 通常の16:9画像と一般的な縦長画像は、従来の読みやすい大きさを維持していること
5. 一覧または編集画面の左下／右下に `v0.21.5` と表示されること
