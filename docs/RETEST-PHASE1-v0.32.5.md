# Phase 1 v0.32.5 再確認手順

v0.32.5は、短いクリック・キー入力が操作記録から抜ける問題と、閉じたダイアログが画面に残る問題を修正した版です。

## 自動検査

Windowsで次を実行します。

```text
tests\phase1\run-tests.cmd
```

最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。

## 目視確認

1. `run.cmd` からManualBuilderを起動し、編集画面のメニューから「操作を記録して手順にする」を開く
2. 「記録を開始」を押し、別のアプリでマウス・タッチパッドのクリックと文字入力を行う
3. ManualBuilderへ戻って「記録を終了」を押す
4. 確認一覧にクリックと入力が別々の操作として表示される
5. 右上または下部の「閉じる」を押し、ダイアログが画面から消える
6. 記録中にも「閉じる」を押し、ダイアログが消えた後にもう一度記録を開始できる
7. 画面左下の版数が `v0.32.5` になっている

## 修正内容

- `GetAsyncKeyState` の現在状態に加え、前回確認後の押下履歴も使って短い操作を検出する
- 閉じた `dialog` は非表示にし、`open` 属性がある場合だけflexレイアウトを適用する
- CSS・JavaScriptのキャッシュを確実に更新するため、配布版数をv0.32.5へ更新する
