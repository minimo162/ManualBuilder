# Phase 1 v0.6.1 Excel主出力 再確認

## 1. 自動テスト

Windows PowerShell 5.1で、リポジトリ直下から次を実行する。

```powershell
tests\phase1\run-tests.cmd
```

`All Phase 1 foundation tests passed.` を確認する。このテストはExcel COMを起動しない。

## 2. Excel COM単体試験

Excelをすべて閉じてから実行する。

```powershell
tests\phase1\run-excel-test.cmd
```

次を自動確認する。

- 出力用Excelの所有PIDを特定できる
- 目次、禁止文字変換、重複シート名、画像埋込みが成立する
- 注釈用派生画像の生成後も元画像が変わらない
- xlsx完成後に出力用Excelプロセスが残らない

## 3. 製品UIでの確認

1. `run.cmd` を起動する。
2. 2シート以上、画像付き手順を合計3件以上作る。
3. 赤枠、赤矢印、番号、黒塗りを少なくとも1件ずつ設定する。
4. シート名へ `/`、`:`、同名を含める。
5. 「Excelで作成」を押す。
6. 作成中も別の手順へ移動し、説明欄へ入力できることを確認する。
7. 完了画面から「Excelを開く」と「保存先を開く」を確認する。

出力先は通常 `ドキュメント\ManualBuilder`。画面は1920×1080・表示倍率100%を標準とし、
目次と各ワークシートを90%表示したとき、画像左・説明右のカードを横スクロールなしで読めるか確認する。
2560×1440・100%でも余白を含めて見やすいことを確認する。

## 4. 安全性と中止

- 作成中に「中止」を押し、未完成xlsxが残らず、編集データが維持されることを確認する。
- 未保存ブックを開いた既存Excelがある状態でも試す。出力が成功するか安全停止するかのどちらかで、
  既存ブックの内容・ウィンドウ・保存状態が変わらないことを確認する。
- 作成を10回繰り返し、タスクマネージャーへ出力用 `EXCEL.EXE` が残らないことを確認する。

## 5. 目視確認

- 目次の並びがアプリのシート順と一致する
- 各シートの手順順がアプリと一致する
- 目次リンクと「目次へ戻る」が機能する
- タイトル、説明、補足が途中で欠けない
- 4種類の注釈が画像の意図した位置に表示される
- 黒塗りは見た目上のマスクであり、元画像を完全削除する機能ではないという運用理解が一致する
