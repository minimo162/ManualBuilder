# Phase 1 v0.5 集中編集・注釈 再テスト

## 自動テスト

ManualBuilderを終了してから、リポジトリ直下で実行する。

```text
tests\phase1\run-tests.cmd
```

次の4つが成功することを確認する。

- `Static tests passed.`
- `Project store tests passed.`
- `Capture store tests passed.`
- `Server integration tests passed.`

## 集中表示と手順移動

1. 同じシートへスクリーンショットを5枚以上追加する。
2. 既定ではカードが1件だけ大きく表示されることを確認する。
3. 左側の手順を順に押し、対象画像と入力欄が即座に切り替わることを確認する。
4. タイトルと説明を入力すると、左のタイトルと状態表示がその場で更新されることを確認する。
5. 「一覧」へ切り替え、全カードの順序確認、ドラッグ、上下移動、削除ができることを確認する。
6. 「集中」へ戻り、直前に選択していた手順が表示されることを確認する。
7. 1920×1080・100%、2560×1440・100%、可能なら1920×1200・150%で主要操作が隠れないことを確認する。

## 注釈

1. 画像右上の「注釈 0」を押す。
2. 赤枠と黒塗りはドラッグ、赤矢印は始点から終点へドラッグ、番号はクリックで追加する。
3. 「選択」で注釈をドラッグ移動し、青い丸を動かして大きさまたは矢印終点を調整する。
4. Undo／Redo、選択削除、すべて削除が機能することを確認する。
5. 「保存」後、カードと画像拡大画面へ注釈が同じ位置に表示されることを確認する。
6. ManualBuilderを終了・再起動し、注釈の種類、位置、番号が復元されることを確認する。
7. 注釈数の表示が保存件数と一致することを確認する。
8. 黒塗りの注意書きに、元画像を保持し完全削除ではない旨が表示されることを確認する。

現時点のExcel／Wordボタンは未接続であり、注釈をOfficeファイルへ合成する確認は次工程で行う。
