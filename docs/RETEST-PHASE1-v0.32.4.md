# Phase 1 v0.32.4 再確認手順

v0.32.4は「操作を記録して手順にする」機能のレビューで見つかった、記録の終了・入力・同一画面の扱いを修正した版です。

## 自動検査

Windowsで次を実行します。

```text
tests\phase1\run-tests.cmd
```

最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。

## 目視確認

1. `run.cmd` からManualBuilderを起動し、編集画面の［その他］→［操作を記録して手順にする］を開く
2. ［記録を開始］を押し、別のアプリで入力欄をクリックして文字を入力した直後にボタンを左クリックする
3. ManualBuilderへ戻って［記録を終了］を押す
4. 確認一覧に「入力」と「クリック」が別々に残り、入力手順の画像では入力欄が黒塗りされている
5. 両方を選んで手順にすると、同じ静止画でも2件の手順になり、それぞれ入力欄とボタンに赤枠が付く
6. もう一度記録し、別のアプリで右クリックする。確認一覧に「右クリック」と表示され、取り込むと操作対象名にも「（右クリック）」が付く
7. 記録中に右上の `×` で確認画面を閉じ、数秒待ってから開き直す。前の記録件数が増え続けず、新しい記録を開始できる
8. 記録開始を押した直後、準備中のまま Esc で閉じても、開き直して新しい記録を開始できる
9. 画面左下の版数が `v0.32.4` になっている

## 修正内容

- 確認画面を閉じた時点で、記録中または開始途中のプロセスと一時画像を破棄する
- 停止処理が4秒以内に終わらない場合は一覧を先に読まず、状態確認を続けて完了後に進む
- 入力を始めた時点の画面を保持し、入力欄を黒塗りして入力手順へ使う。停止要求が入力中に届いても最後の入力を保存する
- 同一画像をSHA-256で共有しつつ、異なる操作は別の手順として作成する
- 左クリックに加えて右クリックの押下も検出し、確認一覧と操作対象名で区別する
