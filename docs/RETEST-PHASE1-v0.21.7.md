# ManualBuilder Phase 1 v0.21.7 再確認

## 目的

アプリ画面とExcel出力で、画像の縦横比が変わっても注釈の視認サイズが揃うことを確認します。

## 自動テスト

```powershell
tests\phase1\run-tests.cmd
```

Excelをすべて閉じてから、次も実行します。

```powershell
tests\phase1\run-excel-test.cmd
```

## 目視確認

同じマニュアルに、次の3種類の画像を用意します。

1. 通常の画面キャプチャ
2. 横長で高さが小さい部分キャプチャ
3. 縦長の部分キャプチャ

各画像へ赤枠と番号を付け、次を確認します。

- アプリ画面では3種類とも赤枠の太さと番号の直径がほぼ同じ
- Excel出力でも3種類とも赤枠の太さと番号の直径がほぼ同じ
- 同じ画像について、アプリ画面とExcel出力の注釈がほぼ同じ大きさ
- 横長画像だけ極端に小さくならず、通常画像だけ極端に大きくならない
- 一覧または編集画面の左下／右下に `v0.21.7` と表示される
