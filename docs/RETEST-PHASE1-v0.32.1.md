# Phase 1 v0.32.1 再確認手順

## 1. 自動テスト

1. Windowsで `tests\phase1\run-tests.cmd` を実行する。
2. `Test-ProjectStore.ps1` で、保存準備に失敗した後も `revision` と `updatedAt` が変わらないことを確認する。
3. `Test-ProjectCatalog.ps1` で、画像を含む配布元データを取り込めること、共有側が新しい場合は「共有版」が1件だけ追加されることを確認する。

## 2. 共有版の巻き戻り防止

1. PC AでHTMLマニュアルを出力し、配布フォルダーの `編集する.cmd` から一度開く。
2. PC Bで同じマニュアルを編集してHTMLを再出力し、共有側の `_source\project.json` を新しくする。
3. PC Aで再び `編集する.cmd` を開く。
4. 古いローカル版が残り、共有側の内容が「- 共有版」の別項目として開くことを確認する。
5. いったん閉じて同じ `編集する.cmd` を再度開き、同じ共有版がさらに増えないことを確認する。

## 3. 基本回帰

- 既存マニュアルの編集と自動保存ができる。
- Excel、Word、HTMLを従来どおり作成できる。
- 同じ内容の配布元を開いた場合は、既存のローカル項目が開く。
