# Phase 1 v0.8.1 画像編集・手順操作 再確認

## 1. 差し替え前

1. ManualBuilder を終了する。
2. Excelをすべて閉じる。
3. ZIPの `ManualBuilder` フォルダーを既存リポジトリへ上書きする。
4. `data` フォルダーは削除・上書きしない。

## 2. 自動テスト

Windows PowerShell 5.1でリポジトリ直下から実行する。

```powershell
tests\phase1\run-tests.cmd
```

`All Phase 1 foundation tests passed.` を確認する。

続けて、Excelをすべて閉じて実行する。

```powershell
tests\phase1\run-excel-test.cmd
```

`Excel COM export test passed.` と `Excel export test passed.` を確認する。

## 3. 集中表示と左ナビ

1. 手順を4件以上用意する。
2. 中央には選択中の1手順だけが表示され、「集中／一覧」切替がないことを確認する。
3. 左ナビの手順をクリックすると中央の手順が切り替わることを確認する。
4. 左ナビのハンドルをドラッグし、順序を変更する。
5. 左ナビの上下ボタンでも順序を変更する。
6. 左ナビの×で不要な手順を削除する。
7. 再起動後も順序と削除結果が保持されることを確認する。

## 4. 画像編集

1. 画像付き手順で「画像を編集」を押す。
2. 切り抜き、赤枠、赤矢印、番号、黒塗りが見つけやすい大きさで表示されることを確認する。
3. 「切り抜き」を選び、画像上をドラッグして必要部分だけにする。
4. 赤枠を1件作り、その直後に赤枠をドラッグして移動する。
5. 青いハンドルをドラッグして大きさを変える。
6. 新しい赤枠が意図せず増えないことを確認する。
7. 「自動保存済み」を確認し、「完了」で閉じる。
8. 再度開き、切り抜きと注釈が残ることを確認する。
9. 「切り抜きを戻す」で画像全体へ戻せることを確認する。

## 5. 表示とExcel出力

1. カード上とクリック拡大表示に切り抜き・注釈が反映されることを確認する。
2. 「Excelで作成」を実行する。
3. Excelの画像が同じ切り抜き範囲・注釈になっていることを確認する。
4. 1920×1080または1920×1200・100%で、カードが従来より約20%広く、画像と説明を同時に読みやすいことを確認する。
5. 横スクロールなし、または最小限の横移動でA:Jのカードを確認できることを確認する。

## 6. 安全性

- 元の画像ファイルが変更されない。
- 既存の未保存Excelブックへ影響しない。
- 出力後に専用の `EXCEL.EXE` が残らない。
- 保存エラー時は画像編集画面が閉じず、再試行できる。
