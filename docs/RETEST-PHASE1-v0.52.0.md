# Phase 1 v0.52.0 再確認手順

## 自動検査

Windowsで次を実行し、最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。

```powershell
$env:CI = '1'
.\tests\phase1\run-tests.cmd
```

## 記録イベントを取り逃した場合

1. 「操作を記録」を開始し、EdgeまたはExcelで画面が変わる操作を数件行います。
2. 記録を終了し、候補の一覧を確認します。
3. 通常のクリック・入力候補に加え、「画面の変化を確認」という要確認候補がある場合は前後画像を確認します。

期待結果:

- 操作イベントが欠けても、安定した前後画像が残っていれば要確認候補として回収される。
- 画像差分だけから作った候補には、近くの別操作の赤枠が付かない。
- 読み込み中の画面や、変化のない連続画像は候補にならない。
- 最初の操作イベントより前に取り逃した操作も、前後画像があれば候補になる。

## 保存失敗からの再試行

1. マニュアル名、シート名、または手順の文章を編集します。
2. 保存先ファイルを一時的に別アプリで占有するなど、保存が失敗する状態を作ります。
3. トップバーの保存状態を確認し、占有を解除して「再試行」を押します。

期待結果:

- 「保存できません」の横に「再試行」が表示される。
- 入力した文字は消えず、再入力や画面の再読み込みを求められない。
- 「再試行」を押すと同じ編集内容を保存し、成功後は「保存済み」へ戻る。

## Excelを作成する導線

1. 手順があるマニュアルを開き、長い手順一覧をスクロールします。
2. 固定表示される確認ツールバーの「Excelで作成」を押します。
3. 出力前確認と出力形式の表示を確認します。

期待結果:

- 「Excelで作成」は確認ツールバーに1つだけ表示され、スクロール中も到達できる。
- 仕上げ状況の欄は説明・画像・要確認の状態だけを示し、出力ボタンを重複表示しない。
- 出力確認ではExcelが標準として先に表示される。
- Wordは「印刷向けにWordで作成」という副出力として選べる。
