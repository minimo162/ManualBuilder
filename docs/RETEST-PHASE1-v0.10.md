# Phase 1 v0.10 画像差し替え・復元 再確認

## 1. 差し替え前

1. ManualBuilderを終了する。
2. ZIPの`ManualBuilder`フォルダーを既存リポジトリへ上書きする。
3. `data`フォルダーは削除・上書きしない。

## 2. 自動テスト

Windows PowerShell 5.1でリポジトリ直下から実行する。

```powershell
tests\phase1\run-tests.cmd
```

`All Phase 1 foundation tests passed.`を確認する。画像差し替えAPI、文章の維持、編集状態の初期化、元画像と注釈・切り抜きの復元がすべて`[OK]`になることを確認する。

Excelをすべて閉じ、既存のExcel出力回帰も実行する。

```powershell
tests\phase1\run-excel-test.cmd
```

最後に`Excel export test passed.`を確認する。

## 3. 画像差し替え

1. タイトル、説明、補足を入力した画像付き手順を開く。
2. 赤枠などの注釈と切り抜きを1つずつ設定する。
3. 画像下部の`画像を差し替え`を押す。
4. 注意文を確認し、別のPNG、JPEG、またはBMPを選ぶ。
5. 同じ手順のまま画像だけが変わり、タイトル、説明、補足が残ることを確認する。
6. 新画像では注釈件数が0になり、切り抜き表示が消えることを確認する。
7. Excel出力を行い、差し替え後の画像が埋め込まれることを確認する。

## 4. 元の画像へ戻す

1. 差し替え後に表示される`元の画像へ戻す`を押す。
2. 旧画像へ戻り、旧画像に付けていた注釈と切り抜きも復元されることを確認する。
3. `元の画像へ戻す`が消え、同じ操作を連続実行できないことを確認する。
4. シートを切り替えて戻っても、アプリを終了しない間は復元ボタンが維持されることを確認する。

## 5. 履歴と安全性

- 差し替えを2回行うと、戻せるのは直前の画像だけである。
- ManualBuilderを終了すると差し替え履歴は終了し、未参照画像が整理される。
- 元画像のファイル自体は変更されない。
- `tests\phase0`に差分がない。
