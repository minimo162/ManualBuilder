# Phase 1 v0.33.2 再確認手順

## 自動検査

Windowsで `tests\phase1\run-tests.cmd` を実行し、最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。

## Power Automate拡張機能の警告

1. PCへMicrosoft Power Automate for desktopがインストールされている状態でManualBuilderを起動します。
2. その他メニューから［操作を記録して手順にする］を開きます。
3. ［記録用Edgeを使う（推奨）］を選んだまま［記録を開始］を押します。
4. 記録用Edgeで任意のWebページを開き、リンクやボタンを数件操作します。
5. ManualBuilderへ戻り、［記録を終了］を押します。

期待結果:

- 「Microsoft Power Automateが追加されました」という拡張機能の警告が表示されない。
- Power Automateを含む拡張機能が記録対象のページを読み取ったり変更したりしない。
- 記録用Edgeは起動直後に閉じず、リンクやボタンのDOM要素名と矩形を取得できる。
- ［記録を終了］を押した場合は記録用Edgeが閉じる。
- 通常利用するEdgeとPower Automateの設定・動作には影響しない。

## 前回プロセスと専用プロファイル

1. v0.33.1以前で起動した記録用Edgeが残っている場合は、そのままv0.33.2から記録を開始します。
2. 記録用Edgeが閉じて起動し直されることを確認します。
3. 記録用Edgeで任意のWebサービスへログインし、記録を終了します。
4. もう一度記録を開始し、ログイン状態を確認します。

期待結果:

- 古い起動オプションのプロセスは再利用せず、拡張機能なしのプロセスとして起動し直す。
- プロセスを起動し直しても専用プロファイルは削除されず、Cookieなどのログイン状態が保持される。

記録用Edgeの起動継続と再接続は [v0.33.1の再確認手順](RETEST-PHASE1-v0.33.1.md)、DOM要素の矩形と表示倍率は [v0.33.0の再確認手順](RETEST-PHASE1-v0.33.0.md) も参照してください。
