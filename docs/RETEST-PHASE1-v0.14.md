# Phase 1 v0.14.1 手順ドラッグ操作 再確認

Windows PowerShell 5.1で、リポジトリ直下から次を実行する。

```powershell
tests\phase1\run-tests.cmd
```

`All Phase 1 foundation tests passed.`を確認する。

## 同一シート内の並べ替え

1. `run.cmd`でManualBuilderを起動し、1シートへ6件以上の手順を作る。
2. 画面左下に`v0.14.1`と表示されることを確認する。
3. 手順左の`⠿`をつかみ、別の手順の上半分／下半分へ移動する。
4. ドラッグ元の行がその場に半透明で残り、行そのものが勝手に移動しないことを確認する。
5. 移動先だけに細い青線が表示され、案内が移動後の位置を示す「N番目へ移動」になることを確認する。
6. 青線上で離し、その時点で初めて順序が確定することを確認する。
7. 「手順の順序を変更しました」と通知され、手順番号と本文カードが同じ順になることを確認する。
8. 再起動後も順序が維持されることを確認する。

## 長い一覧と別シート移動

1. 手順一覧が縦スクロールする件数を作る。
2. 手順をドラッグしたまま一覧の上端／下端へ近づけ、自動でゆっくりスクロールすることを確認する。
3. 手順を別のシート名へ重ね、対象シートが控えめな青色になり「末尾へ」と表示されることを確認する。
4. 案内が「○○の末尾へ移動」になることを確認してドロップする。
5. 移動先シートが開き、「手順を『○○』の末尾へ移動しました」と通知されることを確認する。
6. 画像、タイトル、説明、補足、注釈、切り抜きが維持され、移動先の末尾に1件だけ追加されることを確認する。

## 中止時の確認

- ドラッグ中に`Esc`を押す、または有効な移動先以外で離した場合、元の順序を変えない。
- 現在のシート名へ重ねても別シート移動扱いにしない。
- シート並べ替え用の「ここに移動」と、手順並べ替え用の青い挿入線を混同しない。
