# Phase 1 v0.4 手順操作・表示再テスト

## 自動テスト

ManualBuilderを終了してから、リポジトリ直下で実行する。

```text
tests\phase1\run-tests.cmd
```

次の4つが成功することを確認する。

- `Static tests passed.`
- `Project store tests passed.`
- `Capture store tests passed.`
- `Server integration tests passed.`

## 手順の並べ替えと削除

1. 同じシートへスクリーンショットを3枚以上追加する。
2. カード左上のドラッグハンドル `⠿` で手順を移動する。
3. 上下ボタンでも1件ずつ移動でき、先頭の上ボタンと末尾の下ボタンが無効になることを確認する。
4. 番号が即座に振り直され、ヘッダーが「保存済み」になることを確認する。
5. ManualBuilderを終了・再起動し、並べ替え後の順序が保たれることを確認する。
6. 誤撮影したカードの「削除」を押し、確認でキャンセルした場合は残ることを確認する。
7. もう一度「削除」を押して承認し、対象カードだけが消えることを確認する。
8. 削除した画像と同じ画面をもう一度取り込み、重複扱いされず新しいカードになることを確認する。

## 画像拡大と表示密度

1. カード内の画像をクリックし、画面中央へ拡大表示されることを確認する。
2. `Esc` と右上の `×` の両方で閉じられることを確認する。
3. 1920×1080・100%で、画像とタイトル・説明・補足を同時に把握できることを確認する。
4. 2560×1440・100%で、編集領域が最大1800px程度に収まることを確認する。
5. 1920×1200・150%で、ヘッダーの主要操作とカードの上下移動・削除が隠れないことを確認する。
6. 縦長・横長の画像が切り抜かれず、カード内で全体表示されることを確認する。
