## 目的

## 作成した試作マニュアル

1. ReportBinderのホームを確認する
2. 原稿の登録状況を確認する
3. ページ構成と順番を確認する

5. 変更履歴と比較結果を確認する

各手順に案内画像、タイトル、説明、補足を設定した。手順2〜5には左メニューの対象箇所へ赤枠と番号を付けた。出力前チェックは「説明 5件完了 / 画像 5件あり / 要確認 0件」。Excel出力は成功し、`ReportBinder 基本操作マニュアル 2026-08-10_20260810_131550.xlsx` を作成した。

## 再現した問題

### P1: プロジェクトを切り替えても記録完了バーが残る

記録取込後にマニュアル一覧へ戻り、新しいマニュアルを作ると、前のマニュアルの `2件を追加しました / 続けて記録 / 要確認だけ編集` が新しい空マニュアル上に残った。バーは `document.body` 直下へ追加され、`/api/projects/*` のワークスペース差し替えでは除去されない。

期待: マニュアル一覧へ戻る、別マニュアルを開く、新規作成、複製、削除、取込のいずれでも、前プロジェクトに属する記録結果UIを破棄する。

### P1: 記録対象が前面でなくても無関係な画面差分を手順候補にする

ReportBinderをタブAPIで操作したがOSの前面ウィンドウはCodexのままだった。操作イベントは0件なのに、Codex画面の変化から6件の visual-change 候補が生成された。候補内の大画像を開くまで、対象外画面であることを判断しにくい。

期待: 記録開始直後の基準画面を利用者が確認できること。0操作の画面差分候補では、最初の候補を一件ずつ大きく確認しなくても「どのアプリを撮ったか」を早期に判別できること。汎用的なアプリ同定が難しい場合でも、開始時プレビューと確認チェックを設ける。

### P2: 複数画像取込が長時間無反応に見える

PNG 5枚（約56〜106KB/枚、1907×1008）を一括選択すると、5手順が表示されるまで139.908秒かかった。現在はファイルごとに `/api/images/import` を直列実行し、その都度ワークスペース相当のスナップショットを同期する。利用者には総数、処理済み件数、残り件数が示されない。

期待: ファイル選択直後に `0 / 5` の進捗を表示し、各画像の成功・失敗を集計する。サーバー側のバッチ取込または、最後の1回だけワークスペースを再描画する方式を検討し、少なくとも5枚で数分待たせない。

### P2: 画像取込直後は完成用ツールバーが表示されない

5画像の取込と文章入力・注釈保存後も、`Excelで作成` と `出力前の確認` がDOMに存在しなかった。ページ再読込（625ms）後は即座に表示された。取込中の軽量スナップショット更新だけでは完成用UIが再構成されていない。

期待: 最後の画像取込完了後、通常の `refreshWorkspace()` 相当を一度実行して完成用ツールバーと出力前チェックを表示する。手動再読込を要求しない。

## 確定修正仕様

1. `/api/projects/*` のHTMX要求が成功してワークスペースを差し替えた時点で、`#recorder-complete-bar` を必ず除去する。プロジェクト外へ出る `/api/projects/home` も含める。
2. 複数画像の取込中は選択枚数、処理済み、失敗数を可視化し、最後に一度だけ通常ワークスペースを更新する。
3. 最後の画像取込後は完成用ツールバー、出力前チェック、注釈表示を再初期化する。5枚すべて成功した場合は `5 / 5` と成功通知を出す。途中失敗時も成功分を残し、失敗ファイル名を通知する。
4. 0操作の画面差分候補には、サーバーが確定したプロセス名・ウィンドウ名と最初の基準画像を常時表示する。セッション単位の「このアプリの画面で合っています」確認が済むまで取込を無効化し、サーバー側でも未確認の取込を拒否する。明示開始前の画面は新たに保存しない。

サブエージェントとのレビューでは、アプリを1つに固定する方式は Edge から Excel へ移るような正当な複数アプリ手順を壊すため採用しなかった。また、画像取込はプロジェクト保存の競合を避けるため並列化せず、選択順の直列POSTを維持したまま、各ファイル後のDOM同期を除き、最後の1回だけ `refreshWorkspace()` を実行する最小安全変更に確定した。

## 必須回帰テスト案

- 記録取込後、`projects/home -> projects/create/open` を通ると完了バーが消え、新プロジェクトで `続けて記録` を実行できない。
- 同じプロジェクト内のシート切替では完了バーを勝手に消さない。
- 画像5枚を選ぶと進捗が `0 / 5` から `5 / 5` へ進み、手順順序が選択順と一致する。
- 5枚取込完了後、再読込なしで `Excelで作成`、説明件数、画像件数、要確認件数が正しく表示される。
- 3枚目だけ不正画像の場合、1・2・4・5枚目は残り、失敗1件が通知され、完了後のUIは操作可能。
- 既存の1枚貼付、ドラッグ&ドロップ、置換画像、結果画像の経路は変えない。
