# Phase 1基盤 v0.32.0 再確認手順

Copilotで文章を整える機能を追加し、PowerPoint出力を削除しました。
あわせて、v0.31.0で混入した不具合の修正を確認します。

---

## 0. 最初に必ず確認すること（v0.31.0の不具合）

v0.31.0では、バージョン更新の書き方を誤って **`app.js`・`index.html`・`app-version.json`
の3ファイルを0バイトで出してしまいました**。この版で復旧しています。

| # | 確認内容 | 期待 |
|---|----------|------|
| 0-1 | 起動 | `run.cmd` でManualBuilderが開き、マニュアル一覧が表示される |
| 0-2 | 画面の操作 | 手順の追加・編集・保存が動く（app.jsが読み込まれている） |
| 0-3 | ファイルの中身 | `web\assets\js\app.js` が0バイトでない |
| 0-4 | 自動検査 | `tests\phase1\run-tests.cmd` に `Test-WebAssets.mjs` が加わり、成功する |

**v0.31.0を配布済みの場合は、この版へ必ず更新してください。** v0.31.0は起動しても
画面が動きません。

`Test-WebAssets.mjs` は、この取りこぼしを二度と繰り返さないために追加した検査です。
画面側の資産が空でないこと、バージョンが3か所で一致していること、主要機能の
呼び出しが残っていることをNodeだけで確かめます。

## 1. Copilotで文章を整える

文章の入った手順があるマニュアルで、その他メニューから
**［Copilotで文章を整える］** を選びます。

| # | 確認内容 | 期待 |
|---|----------|------|
| 1-1 | 見出し | 「Copilotで文章を整える」と表示され、見るところが書かれている |
| 1-2 | 注意書き | 「画像は渡しません」と明記されている |
| 1-3 | 絞り込み | 「すでに文章を書いた手順も対象にする」が表示されない（校正では不要） |
| 1-4 | 文章が無い場合 | 「文章が書かれた手順がありません」と案内される |
| 1-5 | 進捗 | 「文章をCopilotへ渡しています」→「文章の確認を依頼しています」と進む |
| 1-6 | 速さ | 画像を渡さないぶん、下書きより明らかに速い |

### 1-7. 指摘の内容

確認のために、わざと次を混ぜたマニュアルで試してください。

- 常体の説明を1つ（例:「「申請」ボタンをクリックする。」）
- 同じものの表記ゆれ（例: ある手順で「ボタン」、別の手順で「ボタン」の送り仮名違い）
- 同じ画面を別の名前で呼んでいる箇所

| # | 確認内容 | 期待 |
|---|----------|------|
| 1-8 | 敬体 | 常体の説明が「〜します。」へ直る |
| 1-9 | 表記ゆれ | 多いほうの書き方へ揃う |
| 1-10 | 種類の表示 | 指摘に「敬体」「表記ゆれ」などの分類が付く |
| 1-11 | 意味 | 意味が変わっていない |
| 1-12 | 余計な指摘 | 手順の順序や操作の是非を指摘していない |
| 1-13 | 直す必要がない手順 | 一覧に出てこない |

### 1-14. 確認画面

| # | 確認内容 | 期待 |
|---|----------|------|
| 1-15 | 今の内容 | 直す前の文章が畳まれず表示される |
| 1-16 | 既定のチェック | 校正では最初からチェックが入っている |
| 1-17 | その場での修正 | 直した文章をさらに手で直してから反映できる |
| 1-18 | 却下 | チェックを外した手順の文章が変わらない |

**重要な確認（1-19）**: 指摘のうち説明だけを直す項目で、手順名の欄が空のまま
反映します。**元の手順名が消えず残る**ことを確認してください。
空欄は「変更しない」の意味です。

## 2. PowerPoint出力が無くなっていること

| # | 確認内容 | 期待 |
|---|----------|------|
| 2-1 | メニュー | その他メニューに「PowerPointで作成」が無い |
| 2-2 | 動画つきの手順 | 「ExcelまたはHTMLで作成すると再生できます」と案内される |
| 2-3 | 動画の添付 | 従来どおり手順へ動画を添付できる |
| 2-4 | Excel出力 | 動画つきの手順があるとフォルダー出力になり、動画が再生できる |
| 2-5 | HTML出力 | 動画がその場で再生できる |
| 2-6 | 旧マニュアル | 動画つきの旧マニュアルを開いても壊れない |

削除の理由: 動画をファイル1つで配れる利点は残るものの、HTMLとExcelが動画に
対応した結果ほぼ重複していました。COM由来の不具合を抱え続ける価値が薄いと判断しています。
