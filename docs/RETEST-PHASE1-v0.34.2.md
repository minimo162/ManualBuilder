# Phase 1 v0.34.2 再確認手順

## 自動検査

Windowsで `tests\phase1\run-tests.cmd` を実行し、最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。

## 手順の一括選択

1. 同じシートに5件以上の手順を作ります。
2. 左の手順見出しにある［すべて選択］を押します。
3. 1件だけチェックを外し、［すべて選択］の表示を確認します。
4. もう一度［すべて選択］を押し、［まとめて移動］または［まとめて削除］を実行します。

期待結果:

- 1回の操作で、そのシートに表示されている手順すべてへチェックが付く。
- 一部だけ選択した場合、［すべて選択］は中間状態で表示される。
- 中間状態から押すと再び全件が選択される。
- ［選択解除］またはチェックを外した［すべて選択］で全件解除できる。
- まとめて移動・削除後に、選択件数とチェック状態が残らない。

## 削除後の保存

1. 画像付きの手順を複数選び、［まとめて削除］を実行します。
2. 同じ操作を数回繰り返します。
3. ManualBuilderを終了して開き直します。

期待結果:

- `File.Replace` の「置換されるファイルを削除できません」というエラーが出ない。
- 削除結果が保存され、再起動後も削除した手順が戻らない。
- `project.json.bak` が一時的に使用中でも、プロジェクト本体は保存できる。
- 正式バックアップを更新できなかった場合は固有名の退避が残り、本体破損時の復旧候補になる。
