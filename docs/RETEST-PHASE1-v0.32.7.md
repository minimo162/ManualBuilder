# Phase 1 v0.32.7 再確認手順

v0.32.7は、「操作を記録して手順にする」の進捗ファイルを画面側が読んでいる瞬間に記録ワーカーの更新が重なると、記録が止まる問題を修正した版です。

## 自動検査

Windowsで次を実行します。

```text
tests\phase1\run-tests.cmd
```

最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。操作記録の検査では、`status.json` を一時的に読み取りロックした状態から更新でき、差し替え後のJSONが完全であることも確認します。

## 目視確認

1. `run.cmd` からManualBuilderを起動する
2. その他メニューから「操作を記録して手順にする」を開く
3. 記録を開始し、別のアプリでクリックやキー入力を10件程度行う
4. 記録中の件数と直前の操作がManualBuilderの確認画面へ更新される
5. 記録を停止し、確認画面に記録した操作が並ぶ
6. 必要な操作を選んで取り込み、画像・赤枠・操作対象が手順へ反映される
7. 同じ操作記録を3回繰り返しても、`status.json` の「別のプロセスで使用されている」エラーが出ない
8. 画面左下の版数が `v0.32.7` になっている

## 修正内容

- 進捗の読み取りを、書き込みと原子的な置換を許す共有モードへ変更
- 進捗JSONを一時ファイルへ完成させてから原子的に差し替える
- ウイルス対策ソフトなどの短時間ロックも考慮し、段階的な再試行を追加
- 一時的な読み取りロックを再現する回帰試験を追加
- 配布版数をv0.32.7へ更新
