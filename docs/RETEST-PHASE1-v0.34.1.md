# Phase 1 v0.34.1 再確認手順

## 自動検査

Windowsで `tests\phase1\run-tests.cmd` を実行し、最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。

## ページ遷移時の画像と赤枠

1. ［記録用Edgeを使う（推奨）］で記録を開始します。
2. リンク、送信ボタン、一覧の行など、押すとすぐ別ページへ遷移する対象を数件クリックします。
3. 遷移が速いページと遅いページ、同じタブ内の遷移と新しいタブを開く操作を含めます。
4. 記録を終了し、確認一覧と取り込んだ画像を確認します。

期待結果:

- クリックした手順には遷移前の画面が残り、その画面上の実際のリンク／ボタンへ赤枠が付く。
- 遷移後の白い領域や無関係な位置へ、遷移前のDOM矩形を使った赤枠が付かない。
- ページタイトルが切り替わった途中の不安定な画面は記録へ使わない。
- DOM対象を取得できない場合は、従来どおりWindows検出またはクリック位置へ戻る。

## 記録用Edgeのプロファイル

1. 記録用Edgeで任意のWebサイトへログインし、お気に入りを1件作ります。
2. 記録を終了してから、もう一度記録用Edgeを開始します。
3. 必要であれば記録用Edgeのプロフィールから普段と同じMicrosoftアカウントへサインインし、同期を有効にします。

期待結果:

- 専用プロファイル内のCookieなどのログイン状態とお気に入りが次回も残る。
- Edge同期が利用できる環境では、許可されたお気に入りや保存パスワードなどを普段のEdgeから同期できる。
- 普段のEdgeプロファイルを直接共有しないため、普段のEdgeを開いたまま記録を開始できる。
- 各Webサイトのログインセッションは同期対象とは限らないため、専用Edge側で最初の1回だけログインする。

エクスプローラーとファイル選択画面は [v0.34.0の再確認手順](RETEST-PHASE1-v0.34.0.md) も参照してください。
