# ManualBuilder Phase 1 v0.25.0 再確認

v0.25.0では、ブラウザーで開けるHTMLマニュアルの出力を追加しました。

## 考え方

Scribe・Tango・Guiddeといったマニュアル作成ツールを調べたところ、3社とも標準でHTML（と埋め込み）を
持っていました。ExcelやWordを開かずにブラウザーだけで読めること、検索と印刷がブラウザーの
標準機能で足りることが理由です。

ManualBuilderのHTML出力は、他の3つの出力と性質が違います。

- **COMを使いません。** 文字列を組み立ててファイルへ書くだけなので、Officeの有無に依存せず、
  既存のブック・文書へ影響することもありません。プロセスが残る心配もありません
- **一瞬で終わります。** COM起動のオーバーヘッドが無いため、別プロセス・進捗表示・中止の
  仕組みを持ちません（手順が多いと画像の焼き込みで数秒かかります）
- **JavaScriptを一切使いません。** 共有フォルダー上のファイルはゾーン判定でスクリプトが
  制限されることがあるため、HTML標準の機能だけで成立させています

## できあがるもの

```
ドキュメント\ManualBuilder\営業システム操作マニュアル_20260803_104500\
├─ index.html          ← ダブルクリックで開く
├─ images\             ← 注釈と切り抜きを焼き込んだ画像
└─ videos\             ← 手順に添付した動画
```

- 左に目次（シートと手順）、右に手順カード（画像・手順名・説明・補足）
- 動画つきの手順は、画面ではプレーヤーを出し、再生前は注釈入りの画像が見えます
- 印刷時は目次と動画が消え、動画つきの手順も静止画で印刷されます

## 目視確認

### HTMLで作成（v0.25.0の追加機能）

1. その他メニューの「HTMLで作成（ブラウザー用）」を実行する
2. 完了ダイアログに `○ 手順 · 画像 ○ 枚 · 動画 ○ 本 · 合計 ○MB` が出ることを確認する
3. 「マニュアルを開く」でブラウザーが開き、次を確認する
   - 左の目次からシート・手順へ移動できる
   - 画像に赤枠・番号・黒塗り・切り抜きが**Excel出力と同じ見た目で**反映されている
   - 動画つきの手順は**その場で再生できる**
   - 説明文の改行がそのまま表示されている
4. 「保存先を開く」でフォルダーが開き、`index.html` と `images`、`videos` があることを確認する

### 共有フォルダーからの閲覧

1. 出力フォルダーを**フォルダーごと**共有フォルダーへコピーする
2. 別のPCから `index.html` をダブルクリックして開く
3. 次を確認する
   - 画像が表示される（フォルダーごとコピーしていないと表示されません）
   - 動画が再生できる
   - **セキュリティの警告が出ずに読める**（JavaScriptを使っていないため）

### 検索と印刷

1. ブラウザーで **Ctrl+F** を押し、手順名や説明文で検索できることを確認する
2. **Ctrl+P** を押し、印刷プレビューで次を確認する
   - 目次が消えている
   - 動画のプレーヤーの代わりに静止画が出ている
   - 手順カードがページの途中で分断されていない
3. 「PDFとして保存」でPDFを作れることを確認する

### 画面幅

1. ブラウザーの幅を狭めて、横スクロールが出ないことを確認する
2. スマートフォンやタブレットで開いても読めることを確認する

### 共通

- 一覧または編集画面の左下／右下に `v0.25.0` と表示される
- Excel・Word・PowerPointの出力が従来どおり動く

## 補足: 開発時に確認済みの内容

**HTML出力はCOMを使わないため、開発環境で完全に検証できました。**
Excel・Word・PowerPointのように「実機でしか確認できない部分」がありません。

- `Test-HtmlExport.ps1`（新規・45項目）— フォルダー名、HTML構造、目次アンカー、
  エスケープ（`<script>` を含む手順名も安全に出力されること）、印刷指定、
  出力フォルダーの生成、未完成フォルダーを残さないこと
- 実際のChromiumで生成HTMLを `file://` から開いて14項目を確認
  - 画像が相対パスで読み込まれること
  - 動画のメタデータを読めて再生可能な状態になること
  - JavaScript無しで目次のリンク移動が効くこと
  - 1280px幅とスマートフォン幅で横スクロールが出ないこと
  - 印刷時に目次と動画が隠れること、PDF化できること

実機では、**共有フォルダーへ置いて別PCから開く**確認だけお願いします。
ここはネットワークとゾーン設定に依存するため、開発環境では再現できません。
