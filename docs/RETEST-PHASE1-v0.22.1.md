# ManualBuilder Phase 1 v0.22.1 再確認

v0.22.1では、撮影のためにManualBuilderのタブが裏へ回るとブラウザーのハートビートが途切れ、
スクリーンショット監視が止まって撮影ぶんが取り込めなくなる不具合を修正しました。

## 何が起きていたか

- 撮影対象タブは10秒ごとにハートビートを送り、サーバーは30秒届かないと監視を一時停止していた
- Chrome・Edgeは、裏へ回って5分ほど経ったタブの `setInterval` を**1分に1回**まで間引く
  （集中スロットリング）。タブが凍結・スリープした場合はさらに止まる
- ManualBuilderは撮影のたびにタブが裏へ回る作りのため、**正常なタブでも猶予30秒を超えて失効**していた
- 監視が止まっている間に届いたファイルは破棄され、タブへ戻っても取り込めなかった
  （再開時に取り込み基準時刻を引き直すため、遡っての取り込みも起きない）

## 何を変えたか

- ハートビートを**Workerのタイマー**から送るようにした。Workerのタイマーは間引きの対象外
  （Workerを作れない環境では従来の画面側タイマーへ自動で戻る）
- 復帰・フォーカス時にも即座にハートビートを送るようにした
- 失効までの猶予を30秒から**90秒**へ延ばした（間引き後の1分間隔でも失効しない）
- 失効しても、既定**15分**は保存先の新着を破棄せず**保留**し、タブへ戻った時点でまとめて取り込む
  （状態表示は `保留中・このタブに戻ると取り込み`）


## 目視確認

### 裏で撮影し続ける（v0.22.1の主要な修正）

1. `run.cmd` で起動し、シートを開く。右上の状態が `● 監視中・このタブに追加` になる
2. ブラウザーを最小化するか別アプリを最前面にして、**10分ほど**そのまま作業する
3. その間に <kbd>PrtSc</kbd> などで**数回スクリーンショットを撮る**
4. ManualBuilderのタブへ戻り、次を確認する
   - 撮影したスクリーンショットが**すべて手順として並んでいる**
   - 右上が `● 監視中・このタブに追加` に戻っている
   - サーバーの黒い画面に `監視を一時停止しました` が出ていない

### タブを凍結・スリープさせた場合

1. 手順は上と同じだが、ブラウザーのタブ スリープ（Edgeの「スリープ タブ」など）が
   働くまで**20分以上**放置してから撮影する
2. タブへ戻ると、保留していたぶんが取り込まれる
   - 15分を大きく超えて放置した場合は取り込まれない。この場合はサーバーの黒い画面に
     `ハートビートが途絶えたため監視を一時停止しました` が出ており、
     タブへ戻った時点から改めて監視が始まる

### 複数タブ

1. 2つ目のタブでManualBuilderを開く
2. 2つ目のタブが `閲覧専用・別タブが撮影対象` になる（撮影対象は1つ目のまま）
3. 1つ目のタブを閉じてしばらく待つと、2つ目のタブが撮影対象へ引き継がれる
   - 引き継ぎ時、前のタブ向けに保留していたぶんは取り込まれない

### 共通

- 一覧または編集画面の左下／右下に `v0.22.1` と表示される
- 貼り付け・ドラッグ&ドロップ・画像選択での追加が従来どおり動く

## 補足

`Start-ManualBuilder.ps1` の `-HeartbeatTimeoutSec`（既定90秒）と
`-CaptureStandbySec`（既定900秒）で猶予と保留時間を変更できます。
`-CaptureStandbySec 0` を指定すると、保留せず従来どおり即座に一時停止します。
