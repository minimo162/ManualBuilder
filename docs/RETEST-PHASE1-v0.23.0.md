# ManualBuilder Phase 1 v0.23.0 再確認

v0.23.0では、録画から場面を選んで手順にする取り込みを追加しました。

## 考え方

「動画をマニュアルに載せたい」という要望に対して、動画そのものをExcel・Wordへ埋め込むことは
形式上できません。代わりに**動画を入力として使い、成果物は従来どおり静止画**にします。
静止画のままにする利点は、該当箇所を探しやすい・印刷できる・検索が効く・部内で追記できることです。

動画そのものを見せたい場合は、動画を共有フォルダーへ置き、手順からリンクする運用で対応します。
（アプリの機能ではなく運用で解決する範囲です）

## しくみ

- 動画は**サーバーへ送りません**。ブラウザーが `URL.createObjectURL` で再生し、
  選んだコマだけを画像にして既存の取り込みAPI（`/api/images/import`）へ送ります
- そのためサーバーから見ると「画像が1枚届いた」だけで、保存・注釈・切り抜き・黒塗り・
  Excel/Word出力はすべて従来の経路がそのまま動きます
- 画質は既定で**長辺1280px・JPEG品質85**です。Excel出力は注釈を焼き込むとき760px幅
  （Wordは600px）へ縮小するため、1280pxあれば出力では常に縮小方向になります。
  切り抜きを多用する場合に備えて「元の解像度で取り込む」も選べます

## 目視確認

### 動画から手順を作る（v0.23.0の追加機能）

1. Win+Alt+R などで操作を録画する（mp4）
2. ManualBuilderでシートを開き、「動画から選ぶ」を押す。または動画ファイルを画面へドロップする
3. ダイアログで動画が再生できることを確認する
4. シークバーと「◀ 0.1秒 / 0.1秒 ▶」で場面を合わせ、「この場面を手順にする」を押す
5. 次を確認する
   - 手順が1つ増え、その場面の画像が入っている
   - ダイアログは開いたままで、続けて別の場面を追加できる
   - 右下の表示が `追加: 2件 ・ 0:12.3 の場面を追加しました` のように更新される
6. ダイアログを閉じ、追加した手順に赤枠・番号・黒塗り・切り抜きを付けられることを確認する
7. Excel・Wordへ出力し、動画から取り込んだ画像が従来の画像と同じように出ることを確認する

### 画質

1. 既定のまま取り込んだ手順の画像を開き、文字が読めることを確認する
2. 「元の解像度で取り込む」にチェックを入れて取り込むと、より大きな画像で入る
   - 切り抜きを強くかける場合はこちらを使う

### 動画が再生できない場合

1. mp4・webm以外（wmvなど）を選ぶか、壊れたファイルを選ぶ
2. ダイアログに `この動画は再生できません。mp4（H.264）またはwebmで録画し直してください。`
   と出て、「この場面を手順にする」が押せなくなることを確認する

### 同じ場面を2回取り込んだ場合

1. 同じ位置で「この場面を手順にする」を2回押す
2. 2回目は手順が増えず、`同じ画面のため追加しませんでした` と出ることを確認する
   - 画像が完全に一致する場合は重複として扱う既存の仕様です

### 共通

- 一覧または編集画面の左下／右下に `v0.23.0` と表示される
- 撮影・貼り付け・ドロップ・画像選択が従来どおり動く

## 補足: 開発時に確認済みの内容

実際のChromiumで、1920×1080のwebmを生成してドロップから取り込みまでを自動確認しています。

- ドロップでダイアログが開き、録画の解像度と長さを読み取れること
- シーク位置のコマがJPEGとして送られ、既定で1280×720へ縮小されること
- 「元の解像度で取り込む」では1920×1080のまま送られること
- 0.1秒送りが効くこと、閉じると動画の参照を解放すること
- 再生できない動画では理由が出て、取り込みボタンが無効になること

実機では、Windowsの録画（mp4/H.264）で上の手順を追認してください。
1コマの容量は画面の内容で変わります（単色に近い画面では十数KB、情報量の多い画面では
数百KB程度）。
