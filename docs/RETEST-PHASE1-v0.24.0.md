# ManualBuilder Phase 1 v0.24.0 再確認

v0.24.0では、動画つきのPowerPoint出力を追加しました。

## 考え方

「動画も見せたい」という要望に対し、動画を再生できる形で運べるのはPowerPointだけです。
Excelは動画を持てず、Wordもアイコンからの外部起動にしかなりません。
そこで**動画が必要な場合はPowerPoint、不要な場合は従来どおりExcel・Word**という使い分けにしました。

- 動画はpptxの中へ取り込みます（リンクではありません）。受け取った人はファイル1つで再生できます
- 動画が必要なのは一部の手順だけという前提で、1本30MB・1マニュアル50本までとしています
- 動画つきの手順でも、再生前に表示されるのは編集済みの画像（赤枠・番号つき）です

## ファイルサイズの目安

共有フォルダーへ置くため、録画の撮り方で大きさが決まります。

| 条件 | 10秒あたり |
|---|---|
| 1080p / 30fps / 既定品質 | 約10MB |
| 720p / 15fps / 1.5Mbps | 約1.9MB |
| 720p / 15fps / 1Mbps | 約1.2MB |

- 該当する操作だけを5〜15秒で撮る
- **全画面ではなくアプリのウィンドウだけを録る**（ウィンドウを小さめにすると解像度が下がる）
- 貼り付けた後でも、PowerPointの ファイル > 情報 > **メディアの圧縮** でまとめて小さくできます

## 自動テスト

```powershell
tests\phase1\run-tests.cmd
```

PowerPointをすべて閉じてから、下の目視確認へ進みます。

## 目視確認

### 動画つきの手順を作る

1. 操作を録画する（mp4・5〜15秒）
2. 「動画から選ぶ」または動画を画面へドロップし、ダイアログを開く
3. 場面を合わせて **「動画つきで手順にする」** を押す
4. 次を確認する
   - 手順が1つ増え、その場面の画像が入っている
   - 手順カードに `▶ 動画つき ○秒 ・ ○MB` と表示される
   - 右下に `追加: 1件 ・ 0:03.2 の場面を動画つきで追加しました` と出る
5. その手順に赤枠や番号を付けられることを確認する

### PowerPointで作成（v0.24.0の主要な追加）

1. **PowerPointをすべて閉じる。** タスクマネージャーの「詳細」で `POWERPNT.EXE` が無いことを確認する
2. その他メニューの「PowerPointで作成（動画つき）」を実行する
3. 進捗ダイアログに `○ / ○ 手順` が出て、完了時に `○ スライド · 動画 ○ 本を埋め込みました` と出ることを確認する
4. 出力後に `POWERPNT.EXE` が**残っていない**ことを確認する
5. 「PowerPointを開く」で開き、次を確認する
   - 表紙 → シート名のスライド → 手順ごとのスライド、の順に並んでいる
   - 手順のスライドに、手順名・画像（または動画）・説明・補足がある
   - 動画つきの手順は、再生前に編集済みの画像（赤枠・番号つき）が見えている
   - **スライドショーで動画をクリックすると再生できる**
6. pptxを別のPCへコピーして開き、**動画が再生できる**ことを確認する
   （リンクではなくファイルに取り込まれているため、元の動画が無くても再生できます）

### PowerPointが開いている場合

1. PowerPointで何かのファイルを開いた状態にする
2. 「PowerPointで作成（動画つき）」を実行する
3. `PowerPointが開いているため、作成を開始しませんでした` と出て、**開いているファイルに影響しない**ことを確認する
4. PowerPointを閉じて再実行すると作成できることを確認する

### 中止

1. 手順の多いマニュアルで作成を開始し、途中で「中止」を押す
2. 中止扱いになり、`POWERPNT.EXE` が残らないことを確認する
3. ManualBuilderの編集内容が変わっていないことを確認する

### Excel・Wordへの影響

1. 同じマニュアルをExcelとWordでも出力する
2. 動画つきの手順も**画像として従来どおり出力される**ことを確認する（動画は含まれません）

### 動画を外す

1. 動画つきの手順で「動画を外す」を押す
2. 表示が消え、もう一度PowerPointで作成すると、その手順が画像だけになることを確認する

### 共通

- 一覧または編集画面の左下／右下に `v0.24.0` と表示される
- マニュアルのZIP書き出し・取り込みで、動画も一緒に運べることを確認する

## 補足: 開発時に確認済みの内容

自動テストで確認済みの範囲です。

- 動画の保存・重複排除・差し替え・付け外し・未参照の後片付け（`Test-VideoAttachment.ps1`、31項目）
- 動画欄の無い旧 `project.json` を読み込んでも壊れないこと
- PowerPoint出力の補助処理（出力ファイル名、進捗ファイル、中止の検知、出力対象シート）
  （`Test-PowerPointUtilities.ps1`、15項目）
- ブラウザーでの動画取り込み（実際のChromiumで生成した1920×1080のwebmを使用、17項目）

**PowerPoint COMを使う部分（スライド生成、動画の埋め込み、プロセスの後始末）は、
Windows実機でのみ動作します。上の目視確認が初回の動作確認になります。**
特に次の2点は実機で必ず確認してください。

- 出力後に `POWERPNT.EXE` が残らないこと（Word出力と同じ安全境界を使っていますが、
  PowerPointは `Visible = $false` を受け付けないため、ウィンドウ無しで作成する方式にしています）
- 動画つきスライドで、編集済み画像が再生前の表示として出ること
  （`MediaFormat.SetDisplayPicture` が使えない環境では、動画の先頭コマが表示されます）
