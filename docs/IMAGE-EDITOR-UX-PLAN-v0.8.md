# ManualBuilder v0.8 画像編集・手順操作 UX 改善計画

## 1. 目的

ManualBuilder の中心作業を「撮影した画面を、迷わず1手順ずつ整えること」に絞る。
今回の対象は、手順ナビゲーション、画像の切り抜き、注釈編集、自動保存、Excel の閲覧幅である。

標準表示環境は 1920×1080 または 1920×1200・拡大率100% とし、2560×1440では余裕を持って表示する。

## 2. 市販製品から採用する操作概念

### 左側で手順を管理する

- Folge は左側の Steps 一覧を、移動、並べ替え、削除などの管理場所としている。
- Tango と Scribe も手順一覧のドラッグ操作を主要な並べ替え手段としている。
- ManualBuilder でも、カード上部に散らばっていた並べ替え・削除を左ナビへ集約する。

### 画像編集を1か所に集約する

- Folge、Tango、Scribe は切り抜き、図形、矢印、番号、秘匿を同じ画像編集工程に置く。
- ManualBuilder の入口は小さな「注釈」ボタンではなく、常に見える「画像を編集」ボタンとする。
- ボタンの補助文で「切り抜き・赤枠・矢印・番号・黒塗り」を明示する。

### 作成直後のオブジェクトをそのまま編集できる

- 図形を置いた直後は自動的に選択状態へ切り替える。
- 続けてドラッグすれば位置を変更でき、端のハンドルで大きさを変更できる。
- 同じ種類を連続作成したい場合だけ、利用者がもう一度ツールを選ぶ。

### 保存状態を利用者に意識させない

- 本文と同様、切り抜きと注釈も変更後に自動保存する。
- 編集画面には「自動保存中」「自動保存済み」「保存できません」を表示する。
- 閉じる操作は「完了」とし、未送信の変更があれば保存完了後に閉じる。

## 3. 画面構成

### 常時表示

- 表示モードは集中表示だけにする。「集中／一覧」切替は廃止する。
- 左ナビに各手順の番号、タイトル、入力状態、ドラッグハンドル、上下移動、削除を表示する。
- 中央には左ナビで選択した1手順だけを表示する。
- カード上部は番号とタイトルだけにして、管理操作を重複させない。

### 画像カード

- 画像の下に十分な高さの「画像を編集」ボタンを常設する。
- 注釈数と、切り抜き済みかどうかを状態として表示する。
- カードと拡大表示には保存済みの切り抜き範囲を反映する。

### 画像編集ダイアログ

- ツール: 選択、切り抜き、赤枠、赤矢印、番号、黒塗り。
- 操作: 元に戻す、やり直す、選択を削除、切り抜きを戻す、すべて削除。
- 切り抜きは画像上をドラッグして指定し、元画像は変更しない。
- 注釈座標と切り抜き座標は元画像に対する 0〜1 の正規化値で保存する。
- 黒塗りは非破壊編集であり、元画像から機密情報を消去する機能ではないことを表示する。

## 4. Excel 出力

- 保存された切り抜きを先に適用し、その後、残る範囲へ注釈を合成する。
- 元画像は変更せず、出力用派生画像だけを作成する。
- 1920px幅・100%表示でカードが画面幅のおよそ75〜80%を使うよう、A:J の列幅を約20%拡大する。
- 画像領域 A:F、説明領域 G:J の約60:40は維持する。

## 5. 互換性と安全性

- 既存 project.json に crop がない場合は全画像範囲 `{ x:0, y:0, width:1, height:1 }` として補完する。
- 切り抜き範囲は最小5%とし、画像外の座標を拒否する。
- Phase 0 の検証資産は変更しない。
- Excel は専用プロセスで生成し、既存の未保存ブックに触れない既存方針を維持する。

## 6. 受入条件

1. 一覧切替がなく、常に1手順だけが中央に表示される。
2. 左ナビだけで手順選択、上下移動、ドラッグ並べ替え、削除ができる。
3. 「画像を編集」がカード上で見落としにくい。
4. 赤枠などを作成した直後、その図形を移動・サイズ変更できる。
5. 注釈と切り抜きが自動保存され、閉じても消えない。
6. 切り抜きがカード、拡大表示、Excel出力に反映される。
7. 既存プロジェクトを開いた場合は従来どおり全画像が表示される。
8. 1920×1080/1200・100%でExcelカードが窮屈にも過度に細くもならない。
