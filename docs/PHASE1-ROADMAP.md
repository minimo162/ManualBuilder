# Phase 1 MVPロードマップ

## ゴール

初回利用者が「1枚撮影 → 説明入力 → Excel作成」を3分以内に完了できる、部内向けMVPを作る。Excelを主出力、Wordを副出力とし、PC画面での読みやすさを優先する。

## 1. 製品基盤

- `src/Start-ManualBuilder.ps1` からlocalhostサーバーを起動する
- 単一インスタンス、空きポート選択、localhost限定、Origin/Host検証を実装する
- `web` の静的ファイルを配信し、既定ブラウザーで開く
- 終了処理と異常終了時の回復を実装する

完了条件: ダブルクリック相当の操作で起動し、ブラウザーを閉じても業務データを失わず、安全に終了できる。

## 2. プロジェクトモデルと自動保存

- プロジェクト、シート、手順、画像のJSONスキーマを定義する
- ID、並び順、作成・更新時刻、削除状態を保持する
- 原子的保存、世代バックアップ、破損時の復旧を実装する
- シート切替時も入力値とスクロール位置を保持する

完了条件: 50手順を編集・並べ替えして再起動しても、順序と入力内容が一致する。

## 3. 編集UI

- 左にシート／手順アウトライン、中央に手順カード、上に保存・監視・出力状態を置く
- シート追加、名前変更、並べ替え（実装済み）、複製、削除、元に戻すを実装する
- 手順名、説明、補足、画像差し替え、並べ替え、別シート移動（実装済み）を実装する
- htmxの部分更新をカード単位に限定し、入力中カードを不用意に差し替えない

完了条件: 1280px幅、Windows表示倍率125%と150%で主要操作が隠れず、キーボードだけでも説明入力を続けられる。

## 4. スクリーンショット取込み

- `Win + Shift + S` の保存先監視
- Ctrl+V、ドラッグ&ドロップ、ファイル選択
- 現在のシート末尾への追加、SHA-256重複除去、画像実体検証
- 1タブだけを撮影対象にし、タブを閉じた後の画像を勝手にバックフィルしない
- 遅延キャプチャとDPI・マルチモニター対応

完了条件: 撮影後2秒以内にカードが現れ、説明欄へ移動できる。

## 5. Excel主出力

実装済み。`tests\phase1\run-excel-test.cmd` と製品UIによるWindows実機試験を通過した時点で完了扱いにする。

- Phase 0の `09-excel-layout.ps1` を製品データ入力へ置き換える
- ユーザー定義シート順、手順順、シート名変換を維持する
- 目次、戻るリンク、画像左・説明右の横長カードを生成する
- 進捗、中止、タイムアウト、原子的保存、自己検査を実装する
- 50手順・100手順の時間、容量、閲覧操作感を測る

完了条件: X-01〜X-13を製品データで再確認し、既存の未保存Excelに影響しない。

## 6. Word副出力

実装済み。`tests\phase1\run-word-test.cmd` と製品UIによるWindows実機試験を通過した時点で完了扱いにする。

- 同じプロジェクトモデルをWordの章・手順へ変換する
- Word起動中は安全に中止し、Excel作成への導線を表示する
- 出力順、画像、説明、補足、未完成ファイル防止を自己検査する

完了条件: 既存の未保存Wordに影響せず、Excelと同じシート順・手順順になる。

## 7. 注釈と仕上げ

- 連番バッジ、矢印、枠、黒塗りを非破壊編集する（基本機能は実装済み）
- Excel／Word出力時に注釈を画像へ合成する
- ぼかしは黒塗りと用途を分け、機密マスクと誤認させない
- 差し替えの元に戻すは実装済み。削除と注釈破棄の復元は今後の仕上げで追加する
- 保存失敗、競合、監視停止、Office利用不可の回復導線
- 初回ガイドと部内向け利用手順

## 8. 部内配備と複数プロジェクト

- 共有フォルダーにはアプリの配布用正本だけを置く
- プロジェクト、画像、実行時情報、一時ジョブは `%LOCALAPPDATA%\ManualBuilder\data` へ分離する（v0.15.0実装済み）
- 旧アプリ配下のdefaultプロジェクトを、削除・上書きせず初回だけローカルへ移行する（v0.15.0実装済み）
- 共有フォルダーの最新版を各PCのローカルキャッシュへ安全に更新してから起動する（v0.15.1実装済み）
- 同じ版では再コピーせず、起動中は更新を保留し、更新失敗時は検証済みローカル版を使う（v0.15.1実装済み）
- プロジェクト一覧、新規作成、名称変更、検索、複製、アーカイブ、復元を追加する（v0.16.3実装済み）
- プロジェクト単位のZIP書き出し／取込みを追加し、メールや共有フォルダー経由でも衝突なく受け渡せるようにする（v0.17.0実装済み）

完了条件: 同じ共有アプリを複数ユーザーが同時起動してもデータが混在せず、更新中断時も直前のローカル版で起動できる。

## Phase 1で行わないもの

- Excel／Wordからアプリへの再取込み
- 共同編集、承認ワークフロー、クラウド同期
- PDF・独立HTMLの直接出力
- AIによる説明文生成
- 厳密な印刷組版
