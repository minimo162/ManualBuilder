# ManualBuilder Phase 1 v0.27.0 / v0.27.1 / v0.27.2 再確認

v0.27.0では、Excelからも動画を開けるようにしました。

**v0.27.1の修正（先に読んでください）**

v0.27.0にはExcel出力が必ず失敗する不具合がありました。
`Excelファイルを作成できませんでした: このオブジェクトにプロパティ 'NumberFormat' が
見つかりません` で止まり、**動画の有無にかかわらずExcel出力全体が使えません**でした。

原因は、手順カードの見出し範囲を次のように書いていたことです。

```powershell
$titleArea = if ($hasVideoLink) { $Worksheet.Range("B1:I1") } else { $Worksheet.Range("B1:L1") }
```

PowerShellでは `if` の値がパイプライン経由で受け渡されるため、**列挙できるオブジェクトは
展開されます**。ExcelのRangeはセルの集合として列挙できるので、Range1個ではなく
セルの配列になり、配列にはプロパティを設定できず上のエラーになっていました。
COMオブジェクトを直接代入で受け取るよう修正しています。

そのため、**この文書の確認はv0.27.2で行ってください。**
最初に「動画が無い場合」を実行し、Excel出力が元どおり動くことを確認してください。

**v0.27.2の見た目の変更**

- 「▶ 動画を見る」を文字リンクから**塗りつぶしのボタン表示**（左のSTEPバッジと同じ濃紺・白文字）へ変更しました。
  文字リンクのままだと見出しの中で埋もれ、同じ行の「目次へ戻る」とも見分けが付きませんでした
- 完了画面の案内文を短くし、次に押すボタン名（「フォルダーを開く」）で直接指すようにしました
- フォルダー出力のときは、ボタン名も「保存先を開く」から「フォルダーを開く」へ変わります

## 考え方

Excelは動画を埋め込めません。ただし、ブックと同じ場所に動画を置けば `=HYPERLINK()` の
相対パスから開けます。相対パスは**クリックした時点で**ブックの場所を基準に解決されるため、
フォルダーごとどこへ移動しても効きます。

そこでHTMLと同じ考え方を持ち込み、**動画つきの手順があるときだけ**Excelもフォルダーで
出力するようにしました。

```
ドキュメント\ManualBuilder\営業システム操作マニュアル_20260803_104500\
├─ 営業システム操作マニュアル.xlsx
└─ 動画\
   ├─ 動画001.mp4
   └─ 動画002.webm
```

動画つきの手順は、見出しの右に「▶ 動画を見る」が出ます。

**動画が無いマニュアルは、これまでどおり単体のxlsxのままです。** Excelの一番の取り柄は
「1ファイルなのでメールで送れる」ことなので、動画を使っていない大多数のマニュアルからは
その手軽さを奪いません。

HTMLの `_source` と違い、この `動画` フォルダーは**隠しません**。中身が見えていた方が
「フォルダーごとコピーするもの」だと分かるためです。また元データ（project.json）は
入れていません。Excelは配るための成果物で、編集の起点はHTML側の `_source` に一本化します。

## 目視確認

### 動画が無い場合（従来どおりであること）

1. 動画を添付していないマニュアルで「Excelで作成」を実行する
2. 次を確認する
   - 保存先に `マニュアル名_日付_時刻.xlsx` が**単体のファイルとして**できる
   - 完了画面に注意書きが**出ない**
   - 「保存先を開く」でこれまでどおり `ドキュメント\ManualBuilder` が開く
   - ブックの中身がこれまでと変わっていない

### 動画がある場合（v0.27.0の追加）

1. 手順のいくつかに動画を添付し、「Excelで作成」を実行する
2. 完了画面で次を確認する
   - 保存先の表示が `マニュアル名_日付_時刻\マニュアル名.xlsx` になっている
   - 「動画つきのため、…下の『フォルダーを開く』から、フォルダーごとコピーしてください」という案内が出る
   - ボタン名が「保存先を開く」ではなく**「フォルダーを開く」**になっている
3. 「フォルダーを開く」を押し、**フォルダーの中**が開くことを確認する
4. フォルダーの中に `マニュアル名.xlsx` と `動画` フォルダーがあることを確認する
5. `動画` フォルダーの中に `動画001.mp4` のような連番のファイルがあることを確認する
6. 「Excelを開く」でブックを開き、次を確認する
   - 動画を添付した手順の見出しの右に「▶ 動画を見る」が**塗りつぶしのボタン**として出ている
   - 添付していない手順には**出ていない**
   - 手順名が長くても「▶ 動画を見る」と重なっていない
   - 1行目の「目次へ戻る」と見分けが付く
7. 「▶ 動画を見る」をクリックし、**動画が再生される**ことを確認する

### フォルダーごと移動しても効くこと（ここが要点）

1. 出力フォルダーを**フォルダーごと**共有フォルダーへコピーする
2. 別のPCから共有フォルダーのブックを開く
3. 「▶ 動画を見る」をクリックし、**再生できる**ことを確認する
4. 念のため、デスクトップなど別の場所へフォルダーごとコピーしても再生できることを確認する

### リンクが切れる場合の挙動

1. xlsxファイル**だけ**を別のフォルダーへコピーする
2. 「▶ 動画を見る」をクリックし、**エラーになる**ことを確認する
   （これは想定どおりの動作です。だから完了画面で「フォルダーごとコピー」と案内しています）

### 同じ動画を複数の手順へ付けた場合

1. 同じ動画を2つ以上の手順へ添付して出力する
2. `動画` フォルダーの中のファイルが**1本だけ**であることを確認する
3. どちらの手順の「▶ 動画を見る」からも同じ動画が再生できることを確認する

### 中止と失敗

1. 動画つきのマニュアルでExcel作成を開始し、途中で「中止」を押す
2. 保存先に `.mb-excel-` で始まるフォルダーが**残っていない**ことを確認する

### 共通

- 一覧または編集画面の左下／右下に `v0.27.2` と表示される
- Word・PowerPoint・HTMLの出力が従来どおり動く

## 補足: 開発時に確認済みの内容

Excel出力はCOMを使うため、開発環境では**生成物を確認できません**。確認できたのは次の範囲です。

- `Test-ExcelUtilities.ps1`（11項目を追加）— 出力フォルダー名の禁止文字・予約名・連番、
  同じ動画を複数の手順へ付けてもファイルは1本になること、拡張子を元の動画に合わせること、
  動画の無い手順にリンクを作らないこと、リンクに絶対パスを使わないこと、
  動画が無ければフォルダー出力にしないこと、動画ファイルが無ければ出力しないこと
- `Test-Static.ps1`（9項目を追加）— `Hyperlinks.Add` ではなく `=HYPERLINK()` 数式を使うこと、
  動画つきのときだけフォルダー出力になること、組み立て途中のフォルダーを差し替え方式で扱うこと、
  出力した動画数を自己検査すること、および **COMオブジェクトを `if` 式の値として受け取らないこと**
  （v0.27.1の不具合の再発防止。Excel・Word・PowerPointの3モジュールを対象に検査します）

**次の2点は実機でしか確認できません。上の「動画がある場合」と「フォルダーごと移動しても効くこと」を
必ず実行してください。**

- `=HYPERLINK()` の相対パスがブックの場所を基準に解決されること（手元での確認は済んでいます）
- 見出し右の「▶ 動画を見る」がレイアウトを崩していないこと
