# Phase 1 v0.32.11 再確認手順

v0.32.11は、操作対象の特定率と対象周辺画像の画質を改善し、複数手順の一括移動・削除を追加した版です。

## 自動検査

Windowsで `tests\phase1\run-tests.cmd` を実行し、最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。

## 操作対象と画質

1. 高解像度画面でManualBuilderを起動し、「操作を記録して手順にする」を開始する
2. EdgeまたはChromeで、通常のリンク・ボタンに加え、独自描画されたメニュー、文字部分、アイコン、カード全体をクリックする
3. 入力欄へ文字を入力し、記録を終了して取り込む
4. Button・Hyperlink以外に、Text・Group・Custom等として公開される対象にも赤枠と対象名が付くことを確認する
5. 操作パターンを公開しない要素でも、クリック点の下に名前付き要素がある場合はその矩形と名前が使われることを確認する
6. 対象周辺表示で文字と赤枠が以前より鮮明で、JPEGのにじみや拡大によるぼけが目立たないことを確認する
7. 「画像を編集 → 切り抜きを戻す」で元のウィンドウ全体へ戻れることを確認する
8. CanvasやリモートデスクトップなどUI Automation情報が無い画面は、従来どおりクリック位置の小さな枠になることを確認する

## 複数手順の移動・削除

1. 同じシートに3件以上の手順を用意する
2. 左側の手順一覧で、離れた2件以上のチェックボックスを選択する
3. 移動先シートを選び「まとめて移動」を押す
4. 選択した手順だけが、選択元での順序を保って移動先の末尾へ移ることを確認する
5. 移動先で複数手順を選択し「まとめて削除」を押す
6. 確認後、選択した手順だけが削除され、共有されていない画像・動画も従来どおり整理されることを確認する
7. 「選択解除」でチェックと一括操作欄が消えることを確認する
8. 移動・削除に失敗した場合、選択状態が残り、再試行できることを確認する

## 修正内容

- 記録画像を長辺2560px、JPEG品質94へ引き上げ
- 高品質バイキュービックで縮小
- UIA子孫検索へText・Pane・Custom・Image・Groupを追加
- LegacyIAccessibleの既定動作と、最小の名前付き要素による補完
- 手順一覧の複数選択、一括シート移動、一括削除
- 配布版数をv0.32.11へ更新
