# ManualBuilder Phase 1 v0.18.0 再確認

## 自動テスト

ExcelとWordを閉じ、リポジトリ直下で実行します。

```powershell
tests\phase1\run-tests.cmd
```

最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。

## 画面確認

1. `run.cmd` で起動し、右下が `v0.18.0` であることを確認します。
2. マニュアル名とシート名に薄い鉛筆が表示され、クリックするとその場で変更できることを確認します。
3. 手順カード右側の先頭が「手順名」になり、入力内容が左ナビへすぐ反映されることを確認します。
4. 上部に「画像から追加」と「文字だけ追加」が並ぶことを確認します。
5. 画像上の「画像を編集」から切り抜き・注釈を開け、「差し替え」も同じ場所から実行できることを確認します。
6. 「文字だけ追加」で空の手順を作り、画像領域の「画像を追加」で画像を設定できることを確認します。
7. 空の手順を選択した状態で画像を貼り付け、同じ手順へ画像が入り、手順数が増えないことを確認します。
8. 画像がある手順で貼り付けると、新しい手順として追加されることを確認します。

## 回帰確認

- マニュアル名、シート名、手順名、説明、補足が自動保存される。
- 画像編集、差し替え、元画像への復元が引き続き利用できる。
- ExcelとWordの出力内容に既存機能からの欠落がない。
