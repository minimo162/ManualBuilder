# Phase 1 v0.35.0 再確認手順

## 前提

- Windows PowerShell 5.1でManualBuilderを起動する
- Microsoft 365 Copilotへサインインできることを確認する
- Copilotへ送信できるテスト画面を使う

## 通常のEdgeとデスクトップアプリの連続記録

1. ［その他］→［操作を記録して手順にする］を開く。
2. 記録用Edgeの選択肢がなく、［記録を開始］だけが表示されることを確認する。
3. 普段使っているEdgeでリンクとボタンを操作する。
4. ファイルエクスプローラーへ切り替え、フォルダーとファイルを操作する。
5. 業務アプリまたはWindows標準ダイアログも1件操作する。
6. 記録を終了する。

期待結果:

- 新しいEdgeプロファイルや記録用Edgeが起動しない。
- 各操作がクリック前の画像で一覧表示される。
- ページ遷移後の空白部分を確定赤枠として表示しない。
- 対象名を取得できない操作も消えずに残る。

## Copilotによる操作解析

1. 明らかに不要な操作だけチェックを外して取り込む。
2. 送信できない文字がある場合は、Copilot画面をいったん閉じ、手順の［画像を編集］で黒塗りする。
3. ［その他］→［Copilotで記録した操作を解析］を開く。
4. ［操作を解析する］を押す。
5. Copilot制御用Edgeへ必要に応じてサインインする。
6. 解析結果を1件ずつ確認する。

期待結果:

- 最初に合成画像の事前確認が走る。
- 1操作につき、操作前全体、操作点周辺、操作後全体の2〜3画像が別チャットへ添付される。
- UIA等の候補が外れていても、前後差とクリック点からリンク、ボタン、入力欄を判断する。
- `keep=false`や要確認の結果は自動削除されず、既定で未選択のまま確認画面に残る。
- 採用すると対象の赤枠、対象名、種類、手順名、説明、補足が同時に反映される。
- 手動で付けた黒塗りは赤枠確定後も残る。

## 入力欄と黒塗り

1. テスト用の入力欄へ文字を入力して記録する。
2. 取り込んだ画像を確認する。
3. 必要な箇所だけ手動で黒塗りし、Copilot解析を実行する。

期待結果:

- 入力文字を自動で黒塗りしない。
- 入力開始前と入力完了後の画像が別々に証跡として保持される。
- 手動黒塗りした箇所はCopilotへ渡す一時画像にも反映される。

## 中断と再実行

1. 複数操作の解析中に［中止］を押す。
2. 再度［Copilotで記録した操作を解析］を実行する。

期待結果:

- 確定していない操作は `pending` または `needs-review` のまま残る。
- 完了したイベントの結果はイベント単位でジョブ結果へ保存される。
- 再実行時も未確定操作を解析できる。

## 既存機能の回帰

1. 手順のまとめて選択、移動、削除を実行する。
2. Excel、Word、HTMLを出力する。
3. 既存プロジェクトを開いて保存する。

期待結果:

- まとめて選択と削除で保存エラーが出ない。
- 操作後画像などの内部証跡は出力へ表示されない。
- v0.34.2以前のプロジェクトは不足した証跡項目を自動補完して開ける。
