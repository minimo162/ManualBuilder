# Phase 1 v0.13.3 シート順・手順移動 再確認

Windows PowerShell 5.1で、リポジトリ直下から次を実行する。

```powershell
tests\phase1\run-tests.cmd
```

`All Phase 1 foundation tests passed.`を確認する。新しい検査として、シート順の保存、
手順の別シート移動、手順IDと文章の維持がすべて`[OK]`になることを確認する。

## 画面確認

1. `run.cmd`でManualBuilderを起動する。
2. シートを3件作り、各シートへ分かりやすい名前を付ける。
3. 画面左下に`v0.13.3`と表示されることを確認する。
4. シート名左の`⠿`を上下へドラッグし、対象シートの前後に青線と小さな「ここに移動」ラベルが現れることを確認する。
5. 左ナビ上部に「○○の前に移動」「○○の後に移動」と表示されることを確認する。
6. 「ここに移動」表示の上で離し、シート順が変わることを確認する。
7. ManualBuilderを終了・再起動し、シート順が維持されることを確認する。
8. 画像、タイトル、説明、補足、注釈、切り抜きを持つ手順を1件用意する。
9. 手順左の`⠿`を別のシート名へドラッグする。
10. 移動先が青く強調され、ドロップ後に移動先シートが開くことを確認する。
11. 移動した手順が移動先の末尾に入り、タイトル、説明、補足、画像編集結果が残ることを確認する。
12. 移動元と移動先の手順番号・件数が自動更新されることを確認する。

## Office出力確認

シート順または手順の所属を変更したあと、ExcelとWordをそれぞれ作成する。

- Excelの目次とワークシート順が左ナビのシート順と一致する
- Wordの章順が左ナビのシート順と一致する
- 移動した手順が移動先シート／章へ一度だけ出力される
- 画像、文章、注釈、切り抜きが移動前と同じ内容で出力される

## 操作上の境界

- シートの`⠿`はシート順の変更に使う
- 手順の`⠿`は、同じ手順一覧内では順序変更、シート名へ落とすと別シート移動になる
- 手順を現在のシート名へ落としても移動は発生しない
- 別シートへ移動した手順は移動先の末尾へ追加する
