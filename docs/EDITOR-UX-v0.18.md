# 編集画面UX方針 v0.18

## 目的

説明文を増やさず、初めて使う人が「どこを編集するか」「次に何をするか」を対象の近くで判断できるようにする。

## 参考にした考え方

- [Folge](https://folge.me/help/guide/getting-started.html): 左に手順、中央に画像、右にプロパティを置き、選択対象と編集場所を分離する。
- [Tango](https://help.tango.ai/en/articles/7966907-how-do-i-use-tango-for-documentation): 手順名、説明、画像を同じ編集工程で扱い、画像編集を対象画像から開始できるようにする。
- [Scribe](https://support.scribehow.com/hc/en-us/articles/9008043510813-Basics-Editing-a-Scribe): 手順追加、文章編集、画像差し替え、並べ替えを作成画面の現在位置から実行できるようにする。

固有の配色、文言、画面構成は複製せず、操作対象の近接性と一貫性だけをManualBuilder向けに取り入れる。

## v0.18の変更

- マニュアル名とシート名に同じ鉛筆表示を置き、クリック編集であることを示す。
- 「タイトル」を「手順名」に統一し、左ナビと右の入力欄で意味を揃える。
- 上部の追加操作を「画像から追加」「文字だけ追加」の2択にする。
- 画像編集と差し替えを画像上の小さなツールバーへ移し、対象との距離を短くする。
- 画像のない手順では、その場に「画像を追加」を表示する。
- 画像のない手順を選択中は、貼り付けまたは1枚のドロップでその手順へ画像を設定する。
- 説明と補足はラベルを維持し、フォーカス中のラベル色だけで現在位置を示す。

## 維持する原則

- 自動保存を基本とし、保存ボタンを増やさない。
- 主操作だけを常時表示し、低頻度・破壊的操作はメニューへ置く。
- 色だけに依存せず、名称、アイコン、フォーカス表示を併用する。
