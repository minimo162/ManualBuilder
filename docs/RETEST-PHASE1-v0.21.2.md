# ManualBuilder Phase 1 v0.21.2 再確認

## 自動テスト

```powershell
cd "$env:USERPROFILE\Downloads\ManualBuilder"
tests\phase1\run-tests.cmd
```

Excelをすべて閉じた後に実行します。

```powershell
tests\phase1\run-excel-test.cmd
```

## 実画面で確認すること

1. 赤枠が編集画面と同じ角丸・太さで表示される
2. 赤矢印が赤枠より少し太く、先端形状も編集画面と揃っている
3. 番号注釈が直径48px前後で、数字が円の中央に表示される
4. 全画面、縦長、細長い切り抜きでも注釈の表示寸法が大きく変わらない
5. 長い説明の末尾が欠けず、カード下部に過剰な空白が残らない
6. 短い説明、補足、縦長画像のカード高さが従来どおり読みやすい
7. Word出力でも赤枠・矢印・番号の形が編集画面に近い

## 期待する自動テスト表示

- `全画面画像の番号注釈を表示直径48px前後にする`
- `細長い切り抜きの番号注釈を表示直径48px前後にする`
- `赤枠を表示太さ7px前後にする`
- `赤矢印を表示太さ8px前後にする`
- `長文を物理行高へ換算して過剰な余白を抑える`
