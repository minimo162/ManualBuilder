# Phase 1 v0.7 Excelレイアウト 再確認

## 1. 自動テスト

Windows PowerShell 5.1で、リポジトリ直下から次を実行する。

```powershell
tests\phase1\run-tests.cmd
```

`All Phase 1 foundation tests passed.` を確認する。このテストはExcel COMを起動しない。

## 2. Excel COM単体試験

Excelをすべて閉じてから実行する。

```powershell
tests\phase1\run-excel-test.cmd
```

`Excel COM export test passed.` と `Excel export test passed.` を確認する。

## 3. 製品UIでの確認

1. `run.cmd` を起動する。
2. 概要が空のシートと、概要を入力したシートを用意する。
3. 各シートへ画像付き手順を2件以上作る。
4. 一方の手順だけ補足を入力する。
5. 赤枠、赤矢印、番号、黒塗りを少なくとも1件ずつ設定する。
6. 「Excelで作成」を押し、完成したxlsxを開く。

## 4. 1920×1080・100%での目視確認

- ブックを開いたときのExcel表示倍率が100%である。
- 手順カードがA～J列に収まり、横スクロールなしで画像と説明を同時に読める。
- カードの左約60%が画像、右約40%が説明である。
- 番号、タイトル、画像、説明が同じカードとして認識できる。
- 概要が空の場合、シート見出しの直下から最初の手順が始まる。
- 概要がある場合だけ、見出しの下に概要が表示される。
- 補足が空の場合、黄色い空欄がなく説明欄が縦に広がる。
- 補足がある場合だけ、薄い黄色と左アクセント線で表示される。
- カード全面が方眼紙状にならず、外周と必要な区切りだけに罫線がある。
- 「目次へ戻る」と目次から各シートへのリンクが動く。

## 5. 2560×1440・100%と補助環境

- 2560×1440・100%では、カードの右側に余白が残っても間延びして見えない。
- 1920×1200・150%では横幅が厳しくなるが、Excelの横スクロールで内容を失わず確認できる。
- 印刷結果は副次確認とし、PC画面での読みやすさを優先する。

## 6. 安全性

- 未保存ブックを開いた既存Excelへ影響を与えない。
- 出力中止時に未完成xlsxを残さない。
- 出力後に専用の `EXCEL.EXE` が残らない。
- 元画像は変更されず、注釈は出力用画像だけに反映される。
