# Phase 1 v0.32.2 再確認手順

v0.32.2では、v0.32.0のPowerPoint出力削除で混入した起動不能と、操作位置の正規化座標・Copilotのパケット分割にあった回帰を修正しました。

## 自動検査

Windowsで次を実行します。

```text
tests\phase1\run-tests.cmd
```

最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。

## 目視確認

1. `run.cmd` からManualBuilderが起動し、マニュアル一覧と編集画面を開ける
2. 「操作を記録して手順にする」でクリックしたコントロールの赤枠が、画面全体ではなく対象の位置と大きさに合う
3. 録画から自動作成した手順で、OCRが使える場合も使えない場合も赤枠が0または画面全体へ潰れない
4. 「Copilotで手順の文章を作る」で対象が既定件数以下の場合、1回のまとまりとして処理される
5. 画面左下の版数が `v0.32.2` になっている

## 修正内容

- `Start-ManualBuilder.ps1` の余分な閉じ括弧を削除
- 入れ子のモジュールが共有モジュールを `-Force` で再読込し、入口スクリプトのコマンドを失わせないよう修正
- 正規化座標の上限・下限計算で `double` のオーバーロードを使うよう修正
- Copilotのパケットが1件だけでも、その中の手順をPowerShellが平坦化しないよう修正
- 構文エラーや不正なfixtureで停止していた回帰試験を修復
