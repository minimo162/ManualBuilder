# Word副出力の設計 v0.11

## 位置づけ

Excelを部内の主出力とし、Wordは縦方向に読み進める文書が必要な場合の副出力とする。同じ`project.json`を入力にするため、シート順、手順順、文章、画像編集結果はExcelと一致する。

## 文書構造

1. 表紙 — 文書タイトル、`操作マニュアル`、作成日、ManualBuilder
2. 自動目次 — シートと手順をWordの見出しから生成
3. シート — 見出し1
4. 手順 — 見出し2。シート内で1から採番
5. 説明 — 通常本文
6. 補足 — 入力がある場合だけ淡い黄色の1セル表
7. 画像 — 切り抜き、赤枠、矢印、番号、黒塗りを合成した派生画像
8. フッター — 中央ページ番号

## デザイン

PC閲覧向けの簡潔なリファレンス文書を基準にし、日本語の部内文書として次の調整を行う。

- A4縦、上下左右20mm
- BIZ UDPゴシックを優先し、利用できない場合はMeiryo等へフォールバック
- 本文10.5pt、表紙タイトル28pt、見出し1は16pt、見出し2は13pt
- 見出しは濃い青、本文は濃い青灰色、補足は淡い黄色
- 画像は縦横比を維持し、最大400×480pt
- 画像へ手順名の代替テキストを付与
- 段落罫線の書式漏れを避けるため、補足は1セル表へ統一

## 安全境界

- 起動前に`WINWORD`が1件でも存在すれば、Word COMを生成せず停止する
- 空のベースラインから作ったWordだけを`Application.Hwnd`とPID差分で識別する
- 所有PIDを確認してから`DisplayAlerts`等を変更する
- `Quit()`は作成用COM参照にだけ実行する
- `Stop-Process`はHwndで所有を証明したPIDにだけ許可する
- `.tmp.docx`へ保存し、保存完了と自己検査の後だけ完成名へ移動する
- 作成失敗時もプロジェクトと既存Word文書を変更しない

## 自己検査

- 出力した手順数が入力件数と一致する
- 埋め込んだ画像数が画像付き手順数と一致する
- Wordが報告するページ数を結果へ記録する
- COM回帰テストではdocx内部を開き、表紙、目次、見出し、説明、補足、画像、代替テキストを確認する
