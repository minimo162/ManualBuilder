# ManualBuilder Phase 1 v0.17.1 再確認

## 目的

マニュアルを画像込みのZIPとして書き出し、同じPCまたは別のPCへ安全に取り込めることを確認します。

## 自動テスト

ExcelとWordを閉じ、リポジトリ直下で次を実行します。

```powershell
tests\phase1\run-tests.cmd
```

最後に `All Phase 1 foundation tests passed.` と表示されることを確認してください。

## 画面確認

1. `run.cmd` で起動します。
2. マニュアル一覧の右下が `v0.17.1` であることを確認します。
3. 一覧に共有フォルダー、更新方式、`%LOCALAPPDATA%` などの開発者向け説明が表示されないことを確認します。
4. マニュアルを開き、左上の `M ManualBuilder` を押すと一覧へ戻ることを確認します。独立した「一覧」ボタンは表示されません。
5. マニュアルカード右上の `…` から `ZIPに書き出す` を選びます。
6. `<マニュアル名>_ManualBuilder_日時.zip` がダウンロードされることを確認します。
7. 一覧上部の `ZIPを取り込む` から、そのZIPを選びます。
8. 同じ内容のマニュアルが別のカードとして追加され、元のカードも残ることを確認します。
9. 取り込んだマニュアルを開き、シート、手順、文章、画像、切り抜き、注釈が維持されていることを確認します。
10. 取り込んだ側を編集しても、元のマニュアルが変わらないことを確認します。

## 安全性の確認

- ManualBuilder以外のZIPを選ぶとエラーになり、既存マニュアルは変更されません。
- 取込みは常に新しいマニュアルとして行われ、同名のマニュアルを上書きしません。
- ZIPの中に未対応ファイル、不正なパス、破損した画像がある場合は取込みを中止します。
