# Phase 1 v0.32.10 再確認手順

v0.32.10は、操作対象名が200文字を超えると取り込みが止まる問題を修正し、操作対象の周辺を読みやすく初期表示する版です。

## 自動検査

Windowsで次を実行します。

```text
tests\phase1\run-tests.cmd
```

最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。

## 200文字を超える操作対象

1. EdgeまたはChromeで、アクセシビリティ名が長いリンク・ボタンを含むページを開く
2. 「操作を記録して手順にする」を開始し、その対象をクリックする
3. 入力欄にも文字を入力し、記録を終了する
4. 確認一覧で対象名が長くても画面が崩れず、末尾が `…` で省略されることを確認する
5. 「選んだ操作を手順にする」を押す
6. 「操作対象は200文字以内で入力してください。」が出ず、すべての選択項目を取り込めることを確認する
7. `project.json` の `capture.clickLabel` が、`（入力）` または `（右クリック）` を含めても200文字以内であることを確認する

## 対象周辺とウィンドウ全体

1. 大きなウィンドウで、小さなリンクまたはボタンをクリックして取り込む
2. 取り込んだ手順で、対象周辺が大きく表示され、赤枠と文字を読み取りやすいことを確認する
3. 「画像を編集」を開き、「切り抜きを戻す」を押す
4. 同じ元画像のウィンドウ全体へ戻ることを確認する
5. もう一度記録し、対象を特定できない余白またはCanvasをクリックする
6. 確認一覧に「クリック位置（対象を特定できませんでした）」と表示されることを確認する
7. 対象不明の操作を取り込んだ場合は、自動切り抜きされずウィンドウ全体が表示されることを確認する
8. 不要な空クリックは、確認一覧でチェックを外して取り込めることを確認する

## 修正内容

- UI Automationの対象名に含まれる改行・連続空白を整理
- 入力・右クリックの補足を含め、操作対象名を最大200文字へ安全に省略
- 元のウィンドウ全体画像を保持した非破壊の対象周辺切り抜き
- 対象不明のクリックは自動切り抜きせず、確認一覧で明示
- 配布版数をv0.32.10へ更新
