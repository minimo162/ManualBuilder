```powershell

```

## 実画面で確認すること

1. 1920×1080画像のカードが14行、1920×1200画像が15行相当となり、画像の下に過剰な空白が残らない
2. 長い説明の白い文章欄が本文の末尾付近で終わり、カードの残りは淡い中立背景になる
3. 補足がある場合は説明の直後に配置され、説明と補足の間へ大きな空白が入らない
4. 小さな元画像や細長い切り抜きが原寸の1.5倍を超えて拡大されない
5. 1.5倍上限になった画像でも、赤枠・矢印・番号の表示寸法がほかの画像と揃う
6. 通常の1920×1080画像は約760×428px相当を維持し、文字サイズも従来どおり読みやすい
