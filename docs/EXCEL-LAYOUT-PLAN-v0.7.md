# Excel出力レイアウト改善計画 v0.7

## 目的

ManualBuilderのExcel出力を、部内でPC閲覧しやすく、必要ならExcel上で文章を直せる手順書にする。
標準確認環境は **1920×1080・表示倍率100%** とし、2560×1440では余白を持って表示できることを狙う。
印刷最適化は副次要件とする。

## 市販製品から取り入れる概念

2026年8月時点の各社公式情報を確認した。製品固有の見た目は模倣せず、次の情報設計だけを採用する。

| 製品 | 公式情報で確認した考え方 | Excelへの転用 |
|---|---|---|
| Scribe | スクリーンショットを切り抜き、注釈・伏字を加え、画像と文章を手順として出力する | 画像を主役にし、注釈合成済み画像をそのまま大きく表示する |
| Tango | スクリーンショット、ハイライト、説明を自動で1手順にまとめる | 番号・タイトル・画像・説明を1つのカード内に保つ |
| Folge | 手順の並べ替え、タイトル・説明、矢印・図形・伏字、複数形式への出力を一体化する | アプリの手順順と注釈を忠実に出力し、Excelでも再編集できるセルを残す |
| Teachme Biz | 1手順ずつのステップ構造と、画像上の矢印・テキストによる直感的な説明を重視する | 1カード1手順を崩さず、番号と画像から順序を追えるようにする |
| iTutor | Word、Excel、PowerPointへのエクスポートを前提とする | Excelを正式な主出力として扱い、シート分割と目次リンクを維持する |

## 採用するレイアウト

### 手順シート

1. 列A～Jを使用し、画像側をA～F、文章側をG～Jとする。
2. 画像側は全体の約60%、文章側は約40%を目安にする。
3. 表示倍率は100%、グリッド線は非表示、先頭行を固定する。
4. 先頭行にシート名と「目次へ戻る」を置き、細いアクセント線で本文と区切る。
5. シート概要がある場合だけ2行目へ表示する。空の場合は余白を残さない。
6. 1手順を12行の横長カードにし、番号・タイトル・画像・説明を同じ視野に置く。
7. 説明と補足は「ラベル行」と「本文セル」を分ける。
8. 補足が空の場合は補足欄を作らず、その分を説明欄へ割り当てる。
9. 補足がある場合だけ薄い黄背景と左アクセント線を付ける。
10. 罫線はカード外周、画像と文章の境界、セクション区切りに限定する。
11. 画像がない手順には、淡い背景のプレースホルダーを表示する。
12. 手順が0件のシートには、簡潔な空状態メッセージを表示する。

### 目次シート

1. タイトル、作成日時、シート一覧を上から順に配置する。
2. シート名はリンクとして維持する。
3. 概要と手順数を一覧で確認できるようにする。
4. 見出し以外は強い塗りや多数の罫線を避ける。
5. 表示倍率は100%、見出し行まで固定する。

## 維持する安全要件

- Excel出力は別プロセスで実行する。
- `Application.Hwnd`から所有PIDを確認してから設定を変更する。
- 既存Excelへ接続した可能性がある場合は安全停止する。
- 一時ファイルへ保存してから完成ファイルへ移す。
- 元画像は変更せず、注釈は出力用コピーへ合成する。
- シート名の禁止文字、重複、31文字制限を処理する。
- Phase 0検証キットは変更しない。

## 完了条件

- PowerShell 5.1で構文エラーがない。
- Phase 1の静的、ストア、サーバー、Excelユーティリティテストが通る。
- Windows上のExcel COMテストで、目次、リンク、画像、注釈、安全終了を確認できる。
- 1920×1080・100%で画像と説明を同時に読み取れる。
- 空の概要・補足が不要な余白や黄色枠を作らない。
