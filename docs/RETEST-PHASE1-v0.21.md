# ManualBuilder Phase 1 v0.21.0 再確認

Excelの各手順カードを、画像の縦横比と説明・補足の文章量に応じた高さへ変更しています。Phase 0の検証キットは過去の基準として変更しません。

## 自動テスト

1. `tests\phase1\run-tests.cmd` を実行します。
2. `横長画像のカード高さを縮める`、`16対9画像の標準カード高さを維持する`、`縦長画像のカード高さを上限まで広げる`、`長い説明に必要な本文行を確保する` がすべて `[OK]` になることを確認します。
3. `All Phase 1 foundation tests passed.` を確認します。
4. Excelをすべて閉じ、`tests\phase1\run-excel-test.cmd` を実行します。
5. `1920x1080画像を約878x494px相当で配置する` と `Excel export test passed.` を確認します。

## 実画面での確認

同じシートに次の4種類の手順を作り、Excelへ出力します。

1. 1920×1080前後の16:9スクリーンショット
2. 横に細長く切り抜いたスクリーンショット
3. 縦長に切り抜いたスクリーンショット
4. 説明を800文字程度入力したスクリーンショット

確認点:

- 16:9画像は従来の約878×494px相当を維持する
- 横長画像の下に大きな空白が残らず、次の手順が早く現れる
- 縦長画像が以前より大きく表示される
- 長い説明の末尾がカード内に表示される
- 補足がある場合だけ補足欄が現れ、説明欄と重ならない
- 手順番号とシート順がアプリの順序と一致する
- 目次、戻るリンク、固定見出し、シートタブ色が従来どおり機能する

## 安全性

- 出力前にExcelを閉じて試験する
- 作成後にExcelプロセスが残らない
- 元画像、注釈、切り抜き、説明文が変更されない
