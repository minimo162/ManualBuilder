# Phase 1 v0.34.0 再確認手順

## 自動検査

Windowsで `tests\phase1\run-tests.cmd` を実行し、最後に `All Phase 1 foundation tests passed.` と表示されることを確認します。

## エクスプローラーとファイル選択画面

1. ManualBuilderの［操作を記録して手順にする］を開き、［その他のアプリを記録する］で記録を開始します。
2. エクスプローラーでフォルダーを開く、ファイルを選ぶ、戻る、パンくずリストを押す操作を行います。
3. Webページや業務アプリの［ファイルの選択］を押し、開いた標準ダイアログでフォルダーとファイルを選びます。
4. 記録を終了し、確認一覧と取り込んだ画像を確認します。

期待結果:

- フォルダーやファイルの名前と矩形を、画面が変わる前の操作対象として取得する。
- 戻る、パンくずリスト、［開く］、［キャンセル］などのボタンへ赤枠が付く。
- クリック後にフォルダー内容やダイアログが変わっても、次の画面にある別要素の名前・矩形を誤って使わない。
- UI Automationを公開しない場所は記録を止めず、従来どおりクリック位置の小さな枠へ戻る。

## 記録用Edgeの赤枠

1. ［記録用Edgeを使う（推奨）］で記録を開始します。
2. 小さなボタン、リンク、ファイル選択欄をクリックし、押した直後にマウスを少し動かします。
3. 表示倍率100%と125%以上、可能ならDPIの異なるモニターでも同じ操作を行います。

期待結果:

- 赤枠はクリック後に読んだカーソル位置ではなく、pointerdown時点のDOM要素へ付く。
- マウスを動かしても赤枠が移動方向へずれない。
- ファイル選択欄でWindowsが内側のボタンを公開する場合は、「未選択」の文字列側ではなく押したボタンへ赤枠が付く。
- ボタンやリンクの名前、種類、矩形を引き続きDOMから取得する。

記録用Edgeの拡張機能と起動は [v0.33.2の再確認手順](RETEST-PHASE1-v0.33.2.md) も参照してください。
